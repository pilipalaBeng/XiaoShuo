## 三、核心规则速记

- **每集流水线**：读基准（**通用规则**/宪法/状态库/**人物档案**/伏笔活表/进度/幕级大纲）→ 定素材 → 写正文 → 跑验收 → 独立审核 → 更新状态库 + **人物档案** + 伏笔活表 + 进度清单 → git commit → 交付
- **写作契约（强制）**：动笔前先读《小说写作通用规则.md》；交付前跑第八节"每集自查清单"；A 类标点铁律全绿方可送审
- **独立审核**：七项硬检查（含"人物连续性"）；打回 ≤3 轮；重大偏离停止并上报
- **决策门**：D1 每集确认；D2 剧情重大调整先登记宪法《修订记录》再更新再续写；D3 发布动作必须用户手动
- **设定合法性**：正文出现的每条新设定须能在宪法找到依据或登记新增，凭空发明 = 打回
- **长篇防漂移**：宪法管不变、状态库管变、**人物档案管人物连续性**、伏笔活表管实况（唯一源）、审核每集拦截；每幕末跑全书大审计
- **外部技能边界**：只做补强不托管流程；产出须过验收 + 审核；与项目文件冲突时以项目文件为准
