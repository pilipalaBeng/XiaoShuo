## 第二部分：AI 写作规则（固定守则，所有书通用）

> **⚑ 本部分是"写作前必读"的入口。**
> 完整的 A/B/C/D/E 五类铁律与每集自查清单，全部收在《**小说写作通用规则.md**》里。
> 本宪法只保留三条最硬的"牙齿"，其余按指引查阅。写任何一集之前，先读通用规则。

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。
规则的目的是保护阅读体验，不是制造新的枷锁。（细则见《小说写作通用规则.md》§0）

### 1. 三条铁律（违者直接打回）
- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排或引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。这是机械可检项，必须清零。
- **句式铁律（B 类）**：禁用"不仅仅是 X，更是 Y"式三连排比；禁用空洞金句收尾、感悟拔高；禁用"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁用万能形容词堆叠（璀璨/神秘/无与伦比……）；同一段内禁止高频复读相同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。

### 4. 交付前自查（强制）
每集写完，对照《小说写作通用规则.md》§九"每集自查清单"逐项打勾；
标点 A 类项由机械扫描确认零违规，B/C/D/E 类由审核 Agent 判定。
**自查未过 = 不得进入验收环节。**
