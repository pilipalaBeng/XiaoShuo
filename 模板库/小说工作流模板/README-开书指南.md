# 小说工作流模板包（通用版）

> 来源：从《荒野规则》项目实战沉淀的管理底盘。v1.1（2026-09-23 新增人物档案制度）
> 定位：**一本书 = 一个独立项目**。本模板包只负责"开书十分钟起步"，不托管任何具体书的设定。

## 三层结构（先分清，再复制）

| 层 | 性质 | 怎么用 |
|---|---|---|
| 通用骨架 | 完全跨书复用 | 原样复制，只改书名 |
| 题材尺子 | 结构通用、指标按品类换 | 在【参数区】按题材选一档 |
| 书本 DNA | 每本书自己的声音 | 只留空表结构，内容全部重填 |

## 开书十步（10-15 分钟）

1. 复制本文件夹整个目录到 `D:\Project\<新书名>\`
2. **通读《小说写作通用规则.md》**——这是所有书的公共契约，写作前必须遵守（标点铁律 A1-A8 等）
3. 填《宪法-模板.md》第一部分"故事圣经"（世界观/人物卡/分集大纲可先填前 10 集）
3. **按题材在《04-验收清单-模板.md》的"题材尺子表"选一档**，替换节奏硬指标
4. 定《文风基准-模板.md》：找 2-3 段你最满意的同类文字做正例（这是全书声音的锚，别跳过）；**同时读《文风执行细则-去AI味与标点规范-模板.md》，把 A 类标点项设为本项目硬门槛**
5. **建《02-人物档案-模板.md》**：把主要/配角人设立卡（从宪法人物卡迁移+补全），"成长轨迹线"从 ep01 起逐集追加
6. 术语表先空着，写作中随出随登记
7. 改 AGENTS-模板.md 里的书名，删掉本项目暂时不用的文件行
8. 07-总纲-模板.md：确认决策门与触发词（默认即通用，可不改）
9. `git init` + 首提交（正文一个字没写也先提交，底座入库）
10. 新会话说"**写下一集**"，流水线启动
11. 第一集验收通过后，回头把文风基准升级为"正反样本尺"（3 正例 + 1 反例）
