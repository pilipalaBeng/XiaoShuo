## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：**《九局归零》**

> **★原创合规声明**：本书游戏名称、标志、服装造型、玩法**全部原创**，不使用"鱿鱼游戏"名称、圆形/三角形/方形组合标识、运动服编号造型等任何既有 IP 元素；玩法采用原创"九局"与民间游戏生死变体，仅作结构设计，不构成对任一作品的模仿。

### 2. 一句话卖点（Logline）
> 为找回被"邀函"带走的妹妹，博弈分析师池砚替她走进密闭的"归零殿"；他不爱体能、只读懂规则——可每破一局，就得交一份属于自己的代价，而第九条规则，连主持者自己也得认。

### 2b. 一句话差异化（★明确写入，四书不得撞车）
> **生死游戏 = 原创淘汰制生死游戏 + 人性实验 + 智斗向**：密闭空间高压规则下的选择博弈，爽点来自"抢在死亡前识破隐藏规则"；与僵尸（B 档但中式民俗志怪单元剧）恐怖来源完全不同，且全程原创、零既有 IP 元素。

### 3. 世界观设定
- **时间 / 地点**：近未来架空；密闭建筑"归零殿"（不对应任何真实地点/机构），由匿名办局者运作。
- **核心规则（力量体系 / 社会规则 / 独特设定）**：
  - 邀函入场：绝境者（负债/绝症/寻人）被"邀函"选中进入归零殿，完成九局可离场并获所求。
  - 每局：开局宣读三条明文规则 + 一条"隐藏规则"（反转来源）；规则确定性是惊悚核心。
  - 代价机制：每局胜者须付"代价"（记忆/信任/物件），禁止零成本赢。
  - 人性实验：部分局设背叛奖励/牺牲机制，揭露人性，比体术高级。
  - 智斗优先：主角靠规则解读/数学/心理赢，体能非决定因素。
  - 出局：淘汰者"出局"（失联离场），血腥细节点到为止。
- **与现实的差异点**：存在"归零殿"与邀函机制这一架空设定；无超自然、无丧尸；纯人性与规则博弈。

### 4. 核心冲突
- **主角目标**：在九局中活到终局、找回妹妹、带幸存者离场，并揭穿办局者目的。
- **最大障碍**：隐藏规则的信息差 + 自身"算尽则孤"的信任代价 + 内鬼与办局方眼线。
- **主要对抗关系**：池砚 / 规则与隐藏规则（智斗主线）；池砚 / 岑岸（办局方眼线）；池砚 / 自身冷算误判（前期不信任同伴的代价）；池砚 / 办局者（终局对"第九条"的博弈）。

### 8. 节奏规则【参数区：取自 04-验收清单 B 档】
- 开场钩子：3 秒内异常/规则压力（邀函、第九条、规则藏刀三选一）。
- 爽点/反转密度：每集 ≥1 个规则反转（识破→反杀）；九局每局必有一反转。
- 结尾要求：悬念钩子必留。

- **可解硬指标**：每局谜题须有公平线索，读者能"抢先猜到"是最大爽点；不可解的死亡=欺诈观众，严禁。

#### 核心体系（游戏 / 规则 / 人性实验，逐条编号）
- **R1 入场契约**：被邀函选中者入归零殿，完成九局可离场并获所求；淘汰=出局（失联离场）。
- **R2 每局规则**：开局宣读三条明文规则 + 一条隐藏规则（反转来源）；规则确定性是惊悚核心，不可临时无厘头改。
- **R3 代价机制**：每局胜者须付代价（记忆/信任/物件），禁止零成本赢；代价印集齐为终局反制条件（V8）。
- **R4 人性实验**：部分局设背叛奖励/牺牲机制，揭露人性，比体术高级。
- **R5 智斗优先**：主角靠规则解读/数学/心理赢；体能非决定因素，不让体术碾压。
- **R6 单元局+主线**：每局淘汰一批 + 揭一层世界真相（谁办/为什么）。
- **R7 出局即失联**：淘汰者离场，血腥细节点到为止；不渲染暴力，走紧张感与氛围。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。
- **原创合规**：书名/游戏名/标志/服装造型一律原创，禁用任何既有 IP（含圆形三角方形标识、运动服编号造型等）元素。
