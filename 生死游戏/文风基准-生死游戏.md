# 《九局归零》文风基准（生死游戏）

> 用途：文风正反样本尺。写作 + 审核对照执行。
> **这是全书声音的锚，开书时务必先填（开书指南第 4 步），不要空着开写。**

## 一、正例（3 段，自写，贴合本书规则怪谈·智斗调性，全程原创无既有 IP 元素）

### 正例 1（开场感）
```
邀函是一张灰卡，没有署名，只写："你欠的，可以还清了。"
池砚把卡翻过来，背面浮起一行小字：归零殿，第九局止。
他没欠钱。他妹欠。
殿门在他身后合拢，墙上缓缓浮出一行字——"第九条，不写。"
整座厅静得能听见别人咽口水的声音。
```
- 好在哪：用"灰卡""第九条不写"等原创物落地规则压力，无形容词堆砌，悬念即开场。

### 正例 2（对白感/规则感）
```
"三条明规。"墙上的声音念，"一、不碰绳者出局。二、绳断者出局。三、最后持绳者胜。"

池砚盯着绳结，没动。

"第四条呢？"他抬头。

墙沉默了两秒。

"……第四条，不写。"声音说。

池砚笑了下："那就是第四条——你没说'不能解'。"
```
- 好在哪：规则即对白，短句带信息差；智斗爽点落在"识破隐藏规则"，原创且可解。

### 正例 3（动作/代价感）
```
灯阵亮起第七盏时，池砚算出路径，迈了三步。
代价印在他腕上烫了一下——是记忆。他忽然想不起妹妹小时候的声音了。
他手停在半空，没出声。
赢一局，丢一段。这笔账，他早料到，还是疼。
```
- 好在哪：代价（记忆流失）用身体与动作呈现，不抒情；规则怪谈的"确定性代价"落地。

## 二、反例（1 段，典型要避免的写法）
```
那一刻，池砚终于明白，游戏的本质是人性的试炼，而人性的本质是虚无。他望着满厅沉默的陌生人，内心涌起一种难以言喻的、苍凉又神圣的终极感悟——或许，这就是命运给予每一个被困者的启示吧。
```
- 差在哪：空泛词（本质、难以言喻、苍凉神圣、终极感悟、启示）+ 感悟拔高 + 大段心理独白，典型 AI 味，与冷峻智斗调性相悖。

## 三、风格要素清单【参数区】

- 叙事人称：第三人称限知（紧跟池砚，必要时切白樱/宋梨）。
- 句长习惯：短句为主，规则宣读段可单列成行制造节奏；可单句成段。
- 段落习惯：允许单句成段（尤其规则浮出、反转落点处）；一段一动作/一信息。
- 标点习惯（破折号用不用？对话用什么引号？——**定了就全书统一，且优先级高于任何外部技能的通用规则**）：
  - 对话统一用 **中文双引号「」**（全书一致，不混用""与『』）。
  - **破折号——全书禁用**（不用——作插入或强调；用逗号或句号断开）。
  - 感叹号克制，单句至多 1 个；反转靠规则与短句承载。
  - 省略号用「……」六点，不用三个点。
  - 规则条文可逐条单列，用"一、二、三、"中文序号，清晰可读。
  - **本表优先级高于任何外部技能的通用文风规则，包括去 AI 味技能的通用禁则。**
  - **执行说明（2026-09-23 用户拍板）**：正文标点一律以本规则表为唯一执行标准（对话用「」、全书零破折号——、省略号六点……）；上文正例 1–3 中出现的弯引号""与破折号为草稿残留，不回改，凡与规则表冲突以规则表为准。
- 口头禅/语言指纹：池砚「这笔账我早算过」「第四条呢？」；白樱「我记着呢」；宋梨「先救人」；叙事者冷感白描，不拟人化规则（写"墙上声音"用"它"）。
- 比喻密度上限：≤1 处 / 500–800 字（规则可用器物类比，禁止抒情长喻）。

## 四、禁用清单（继承宪法第二部分"去 AI 味自查项"，本书特加项）

- 禁：用"命运""神圣""终极感悟"等空泛词收尾。
- 禁：出现任何既有 IP 元素——圆形/三角形/方形组合标识、运动服编号造型、非原创游戏名（如椪糖/弹珠/拔河等）；本书游戏名仅用原创"九局"（翻花绳/灯阵/投信/天平/镜子/盲棋/回声/终选/归零）。
- 禁：血腥渲染；出局走紧张感与氛围，细节点到为止。
- 禁：不可解的死亡（欺诈观众）；每局谜题须有公平线索。
- 禁：代价只用"他很遗憾"带过——须落到可证损失（记忆/信任/物件）。
- 禁：全员同腔调；池砚冷准、白樱细静、宋梨理智温柔、顾淮话术稳、岑岸阴藏，对白可一眼区分。
