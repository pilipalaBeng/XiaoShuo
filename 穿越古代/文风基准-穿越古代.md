# 《锦绣账》文风基准（穿越古代 · 古言经商/种田）

> 用途：文风正反样本尺。写作 + 审核对照执行。
> **这是全书声音的锚，开书时务必先填（开书指南第 4 步），不要空着开写。**

## 一、正例（3 段，从最满意的同类文字中选或自写）

### 正例 1（开场感）
```
水是凉的。

贺织呛出半口水，听见外头砸门声："贺家欠的八十两，今儿不给，搬东西！"

她撑起身，原主记忆涌上来——贺家庶女，布庄亏空，嫡母昨夜把她推下了池子。

"账。"她开口，嗓子哑，"把三年的账，拿来。"

门外的嚷声，奇异地停了一息。
```
- 好在哪：以溺水和砸门双冲突开场（A档3秒冲突）；主角第一句"账拿来"立住人设；不抒情。

### 正例 2（对白感）
```
赵元朗把匾一放："贺家庶女，不懂行。"

贺织瞥了眼匾："赵少东家亲自来挂？"

"你——"

"匾我收了。"她转身，"明日挂去你赵家对门，省得路人看不懂。"

赵元朗脸一青。阿绫在后头，差点笑出声。
```
- 好在哪：短句≤20字，少东家傲、女主稳、丫鬟活三方腔调分明；打脸在动作里。

### 正例 3（动作/情绪感）
```
裴砚把账册摊开，指尖点在一行："东家看这。"

贺织俯身。墨迹旧，数目却对不上。她抬眼："你前东家，是被人栽了。"

裴砚手一颤，十年没人对他说过这句话。

他慢慢跪下，额角抵着青砖："贺家若用我，这辈子不二主。"
```
- 好在哪：以"指账—俯身—抬眼—跪"的动作链承载信任；情绪落在"额角抵青砖"，不写心理。

## 二、反例（1 段，典型要避免的写法）

```
那一刻，贺织终于明白，商场如战场，而她，便是这锦绣山河间最璀璨的、不可战胜的、属于女子的传奇。命运的齿轮悄然转动，仿佛整个世界都在为她的觉醒而欢呼——是啊，这世间又有什么能阻挡一颗永不言败的心！
```
- 差在哪：空洞金句+排比三连（璀璨的/不可战胜的/属于女子的）+破折号感叹+感悟拔高；零信息量。

## 三、风格要素清单【参数区】

- 叙事人称：第三人称限知（紧贴贺织，偶尔借裴砚/阿绫切口）。
- 句长习惯：偏短句（A档爽文节奏），商战解析可略长但不超过 3 行。
- 段落习惯：单句成段用于打脸/反转；不写大段心理独白。
- 标点习惯（破折号用不用？对话用什么引号？——**定了就全书统一，且优先级高于任何外部技能的通用规则**）：
  - 对话统一用「」直角引号（古言语境）；
  - 破折号克制，全书不超 1 处/千字，禁止连用；
  - 感叹号仅短促爆发，禁止堆砌；
  - 账目/数目用阿拉伯数字或汉字统一（本书用汉字数字：八十两、三州）。
- 口头禅/语言指纹：贺织爱"账拿来""这规矩我立"；赵元朗爱"你——"；裴砚少言多"东家看这"。
- 比喻密度上限（建议 ≤1 处/500-800 字）：商战喻体（棋、网、印），不用宏大抒情喻。

## 四、禁用清单（继承宪法第二部分"去 AI 味自查项"，此处列本书特加项）

- 禁止用"传奇""觉醒""锦绣山河"等词直接点题。
- 禁止降维无成本（造玻璃/暴富须落地工匠原料，违则吃设定）。
- 禁止雌竞与情色暗示（纯爱向，感情线清水）。
