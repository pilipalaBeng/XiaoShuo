## 二、人物核心卡（静态人设 + 深化补充）

> 宪法人物卡只有主要角色；本区**补齐所有有戏份的角色**（含配角/反派/暗线），
> 并把宪法原卡升级为"含轨迹"版本；"深化补充"记录宪法未写、正文已确立的人设细节。

### 【贺织】主角

| 字段 | 内容 |
|---|---|
| 身份 | 现代连锁超市买手，穿越成大雍贺家庶女 |
| 核心欲望 | 表层：重振贺家商号、建立"锦绣账"商业网 / 深层：立一套"童叟无欺"的规矩，替原主把没做完的事做完 |
| 致命弱点 | 初期不熟古代律法人情（用现代逻辑硬套会踩坑）；把"护下人"排在"算得失"前面，容易被情感拖累决策 |
| 性格标签 | 冷静、算路清、护下人、礼数上不低头 |
| 成长弧光 | 外来者 → 掌事庶女 → 商印主事 → 三州立规者 |
| 口头禅/标志 | 「账，拿来。」/ 遇事先让人拿账册 |
| 核心关系 | 柳氏（嫡母/仇人）；裴砚（心腹）；贺绫（丫鬟/族妹）；赵元朗（对手转盟）；贺老太君（赏识者） |

**人设深化补充（宪法未写、正文已确立）**
- 落水醒来第一句是「账。」——用"算账"应对一切危机，是她的核心行为标志（ep01）。
- 现代知识必须落地：新货三天后到、替代料染褐，从不凭空变货（R4 约束），续写须保持。
- 对原主的态度是"替她活"而非"取代她"：ep27 她把原主的两封信、一支簪锁进匣子。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。从已写正文中提炼"人物不可越过的线"。

1. **贺织解决危机必先"算账"**：任何做法都要有账目/成本的落脚点，不写她靠嘴炮或运气取胜。
2. **现代知识必须付落地成本**（R4）：不写"凭空造货/凭空暴富"，新玩法须有工匠、原料、染色支撑。
3. **贺织护下人但不圣母**：她会替贺绫、小顺子、王婶子出头，但不会为救人把生意搭进去。
4. **柳氏始终体面**：不写她破口大骂、撒泼；她的最强情绪是"你不是她"式的冷。
5. **裴砚不解释、不诉苦**：他的翻案靠"两本账并排"，不写他长篇自辩或哭诉冤屈。
6. **贺绫不改口**：她只改称呼礼仪，不改那句「姑娘」；不写她突然伶牙俐齿赢过所有人。
7. **赵元朗的转盟是"算"的不是"服"的**：不写他"被贺织的人格感动"而跪下。
8. **老太君不越界**：交权后退隐，不写她中途出山替贺织做主。
9. **陈嫂/刘掌柜不得被随手写死或写废**：他们是被查穿暂不动的雷，续写须保留张力，回收时须有铺垫。
10. **陈嫂的"不知情"是硬设定**：她至今不知被反间，不写她突然明白过来。
11. **反派失败必有成本与后果**：柳氏认罪不是"被打倒"，是"被认下来"；不写廉价的惨败。
12. **架空大雍，不影射真实朝代/人物**：朝堂仅作背景；轻宅斗重搞钱，冲突主源必须是商战。
13. **感情线若有走清水**：纯爱向无雌竞，不写争风吃醋式桥段。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC（宪法使用说明第 1 条亦强制要求）。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §人物卡 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
5. **本档案特殊约定**：第一幕（ep01-ep30）V1-V8 全部回收，轨迹锚点中已标注编号；第二幕新伏笔待宪法/幕级大纲更新后补，新增人物（如苏慕之）须先在本档案建卡。
