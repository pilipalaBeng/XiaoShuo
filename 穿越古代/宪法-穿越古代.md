## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（工作书名）：《锦绣账》
- 备选书名：①《穿成没落商贾庶女》②《算盘有声》③《千金铺》
- 题材 / 类型：穿越古代（古言经商 + 轻宅斗 + 种田）
- 预计总集数 / 单集字数：约 120 集 / 单集 1600–2200 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：18–40 岁女性，爱古言搞钱、轻宅斗重经营
- 验收尺子档位：A 短剧爽文档（节奏指标按 04-验收清单〇节该档替换；知识运用细节决定口碑上限）

### 2. 一句话卖点（Logline）
> 现代连锁超市买手贺织穿成即将破产的大雍贺家庶女，债主堵门、嫡母算计，她用会员制、连锁经营和一张"锦绣票引"把濒临倒闭的布庄做成横跨三州的商业网——降维的是脑子，立住的是规矩，赚的是银子不是男人的心。

### 3. 世界观设定
- 时间 / 地点：架空古代"大雍"（虚构王朝，免史实争议），商业都会+三州商路；朝堂为商争舞台（仍不影射真实朝代/人物、不写真实事件、不写成宫斗，服务于商战）。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 行会规矩：布行有行规，女子主事需过"商印"关（R2 票引须官认）。
  - 商战即战场：价格战/渠道战/原料战，替代宫斗为主冲突（轻宅斗重搞钱）。
  - 落地成本：现代知识须有工匠、原料、染色支撑才可信（R4 约束，防无代价碾压）。
- 与现实的差异点：完全架空，无真实朝代/人物；商业逻辑现代但器物古代。

### 4. 核心冲突
- 主角目标：重振贺家商号，建立"锦绣账"商业网。
- 最大障碍：女子身份受限 + 嫡母掏空 + 对手商行赵家围剿 + 不熟古代律法。
- 主要对抗关系：贺织 vs 赵家商行（赵元朗）；贺织 vs 嫡母内斗。

### 6. 核心体系（金手指 / 优势来源，逐条编号）

- **R1 现代商管**：会员制/连锁/账期/计件工资；代价——须适配古代器物与人力，不能凭空变货。
- **R2 信用票引**：类汇票，可异地取货；代价——须官认、防伪，越界即挤兑反噬。
- **R3 情報网**：伙计+市集耳目，低价知行情；代价——谍报有假，须反间。
- **R4 落地成本约束**：降维打击须讲原料/工匠/染色（如替代料染色更牢），违之则吃设定。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。

### 4. 本书特加红线（差异化契约）
- 架空大雍，不影射真实朝代/人物；朝堂为商争舞台（不写成宫斗）。
- 轻宅斗重搞钱：冲突主源是商战，宅斗为辅（与纯宅斗古言区隔）。
- 降维须落地成本（R4），禁止"凭空造玻璃/凭空暴富"式无代价碾压。
- 纯爱向无雌竞，感情线若有走清水。
