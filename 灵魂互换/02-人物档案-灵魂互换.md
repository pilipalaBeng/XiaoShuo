## 二、人物核心卡（静态人设 + 深化补充）

### 【阮迟】主角（人） · 社恐插画师

| 字段 | 内容 |
|---|---|
| 身份 | 29 岁自由插画师，社恐，欠租三个月；住在栖梧市拾穗巷 602；母亲早逝、父亲三年前工地坠楼"意外"身故 |
| 核心欲望 | 表层：交上房租、把烂掉的事业立起来；深层：**查清父亲死因真相、活成"值得被等的人"** |
| 致命弱点 | **摆烂成习、不敢跟世界要东西**（"他以前出门买个早饭都要做五分钟心理建设"）；对人不敢开口，对猫反倒会说 |
| 性格标签 | 闷、怂、**心里有火不敢点**；话短、多用动作；观察细（能认出笔迹、认出围巾针脚） |
| 成长弧光 | 摆烂欠租 → 被父亲（附猫身）拎着把生活捋顺 → 主动查案、敢推回封口费 → 敢争、敢开口 |
| 口头禅/标志 | 短句、欲言又止；数位板、还款计划 A4、项圈、结案报告、工具箱（半张照片） |
| 核心关系 | 元宝（他的猫/父亲，V1）；罗姨（房东，**认得他爸**）；郑之桐（编辑/事业搭档）；蒋婆婆（邻居，与父亲有旧）；韩茂（杀父疑凶） |

**人设深化补充（宪法未写、正文已确立）**
- **他的"怂"是具体的身体语言**：他的背"从来不直，二十九年了，佝偻着，像总在躲什么"；站起来"总要扶一下桌沿"；手"不知道往哪放"。**写他的心理状态要通过体态，不通过内心独白**。
- **他"敢"的方式是"不开口但不动摇"**：ep16（计划）"阮迟当着猫的面，把钱推了回去"——**他的反抗靠动作，不靠语言**。
- **他的画是他与父亲唯一的连接**：专栏《工地上的父亲》用"插画+查案"双线写父亲——**他的职业能力就是他的调查方式**（画得细、看得细）。
- **他有个反复的动作**：把纸揉掉又捡回来展开压平（ep03 模仿父亲的字迹时）——**这是他"舍不得"的表现形式**。
- **他对元宝的态度是暗线的温度计**：从 ep01 的"我的猫"→ ep03 不敢往那个方向想→ ep10"第一次意识到元宝可能等不到他把所有事情查完"——**他先接受猫会死，才可能接受猫是父亲**。

### 【元宝（阮建国）】主角（猫） · 父亲转世

| 字段 | 内容 |
|---|---|
| 身份 | 五岁橘猫、八斤半——真实身份：失踪三年、已身故的父亲阮建国转世（V1）；转世身按"猫寿"倒数衰减（R5） |
| 核心欲望 | 儿子能好好活；自己的死因有个交代；完成未了心愿 |
| 致命弱点 | **猫身做不了人事**；越接近真相越接近"换不回"；猫寿时限 |
| 性格标签 | **猫时懒，人时稳，话少句重**；背挺得笔直、坐姿像"戴安全帽的人"；不撒娇、逐个"点数"式看人 |
| 成长弧光 | 以猫身回来 → 借儿子的人身替他捋顺生活、查案 → 与儿子"摊牌式"长谈（ep21 计划）→ 弥憾、放心离开（ep30 计划） |
| 口头禅/标志 | "迟儿。"；"别急。"；"回来了。"；猫爪描照片、拱背哈气护人、项圈 |
| 核心关系 | 阮迟（儿子/铲屎官）；罗姨（旧识）；蒋婆婆（旧交情）；郑之桐（间接）；韩茂（旧上司、死因相关人） |

**人设深化补充**
- **他的"人味"藏在姿态里，不靠台词**：ep01 他坐在转椅上"背挺得笔直，肩膀打开，下巴微微收着"；走路的步子"很稳，膝盖不软"；摸猫的手势是阮迟自己摸猫的手势——**写他必须靠"姿态/动作/手感"来体现"这里面是个人"**。
- **他表达爱的方式是"做事"**：用阮迟的手回编辑消息、列还款计划（ep02）、护住阮迟（ep07 拱背哈气）、用爪子描照片上自己的脸（ep03）。**他不说爱，他处理问题**。
- **他是"有分寸的入侵者"**：ep03 他用爪子描照片"不挠，不抓，就是顺着那条轮廓走"——他所有行动都克制、不破坏，符合"父亲"的身份。
- **他的时限是自我牺牲的倒计时**（R5）：转世身加速消耗，**他知道，但不强调**；他的"话少句重"里有对时限的沉默承担。

| 成长弧光 | 前史人物：工地事故身亡 → 三年后以猫身回来（V1） |
| 口头禅/标志 | "迟儿。"；叫儿子小名的低缓语气；短袖、塑料别针（遗物）；全家福里"笑得露出牙"的样子 |
| 核心关系 | 阮迟（儿子）；罗姨（旧识）；蒋婆婆（旧交情）；韩茂（旧上司/加害方） |

**人设深化补充**
- **他的形象由"记忆碎片"拼成**：ep01 阮迟记忆里"一个戴安全帽的人摘了帽子，也是这么坐的"；ep03 全家福"他五六岁，骑在一个男人脖子上…头发剃得短，发际线还没退"；ep03 元宝说话的语气"小时候他发高烧，那个人坐在他床边…叫他的小名"。**写他必须引用这些既有碎片，不得新编性格**。

- **⚠️ 命名规范**：当描写"猫身里的父亲"时用"元宝"；当描写"前史/身份揭示"时用"阮建国"。**两者同一人，不可写成两个角色**。

## 三、成长轨迹线（每个主要人物一行一锚点 · 只增不删）★本档案核心价值区

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从 ep01–ep10 正文里提炼的"人物不可越过的线"。

1. **猫全程不能再说人话**（守线清单第 8 条）：ep03 是全书唯一例外（R2 补登记），**此后每次出现人言都是违规**；写元宝必须靠动作/姿态/顶字表达。
2. **元宝的"人味"必须靠姿态与动作体现**：坐姿笔挺、步子稳、指甲剪齐、掌心有茧、摸猫的手法——**禁止用内心独白直接写"我是父亲"**。
3. **阮迟的心理必须靠体态与动作写**：背不直、站起来扶桌沿、手不知道往哪放、揉纸又捡回来——**禁止大段内心感悟**。
4. **阮迟"敢"的方式是动作不是语言**：他反抗靠"把钱推回去"这样的小动作；**写他突然慷慨陈词即 OOC**。
5. **罗姨必须"硬话—软动作"成对写**：脸硬眼不狠、说赶人后面跟"我没涨过你房租"、伸手想摸猫又缩回去——**只写一头就失真**。
6. **罗姨不是反派**：她是被上面压着催搬的中间环；**不得写她主动加害或与韩茂合谋**。
7. **"茂哥"≠韩茂（ep17 前）**：V6 未坐实前不得画等号，罗姨电话里的称呼是唯一信息（守线清单第 6 条）。
8. **V1 未闭环（ep11–ep21 前）**：不得让阮迟把"项圈笔迹＝互换手＝父亲"三环闭环，**留 ep22**（守线清单第 1 条）。
9. **V3 未全句**：项圈刻字只露"迟儿别等"，**全句 ep24 才浮现**（守线清单第 3 条）。
10. **V4 未回收**：工具箱 ep13 失窃变奏、ep25 才回收；**中途不得提前交出完整照片与手记**。
11. **V5 未回收**：蒋婆婆 ep20 才道出"最后那天"真相；**此前只能给"想说—咽回去"的拉扯**。
12. **R4（猫鼻旧影）守 24 小时边界**：只能"闻"出 24 小时内留下的活动残影；**不得闻出三年前的气味**。
13. **R5 只递"时限紧迫"**：不得让阮迟把猫寿衰减解读为"父亲转世"的证据（守线清单第 10 条）。
14. **阮建国（前史）与元宝（猫身）是同一人**：命名严格区分——猫身场次用"元宝"，前史/身份揭示场次用"阮建国"，**禁止写成两个角色**。
15. **韩茂的结局必须依法办**（宪法特加合规项）：不写私刑复仇；查案落在证据与程序层面；工地事故还原不渲染血腥。
16. **动物不受虐待描写**：猫的伤病仅作时限设定服务，点到为止（宪法特加合规项第 3 条）。
17. **喜剧壳先行、泪点后置**：笑泪比例约 6:4；每集 ≥1 个情感钩子（人猫错位笑点/父子暗糖/查案推进）。
18. **双"主角"声线分明**：阮迟闷怂（话短、多用动作）；元宝（人形时）话少句重、偶带猫腔。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区（宪法 §5 人物连续性指引强制要求），确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）；⑤ 核对状态库"守线清单"十条。
3. **分工不重叠**：
   - 宪法 §5 人物卡 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标）+ 守线清单（每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
5. **人名以《术语表-灵魂互换》为准**：阮迟（非阮池/阮持）、元宝（非元圆/圆圆）、阮建国（非阮建/老阮）、罗姨（非老罗）、郑之桐（非郑桐/之桐）、蒋婆婆（非蒋奶奶）、韩茂（非涵茂）；名词：栖梧市（非栖州）、拾穗巷（非穗巷）、锦帆工地（非锦凡）、猫项圈、工具箱、《工地上的父亲》。
