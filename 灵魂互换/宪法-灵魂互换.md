# 《灵魂互换》宪法

> 用法：每开一部新书复制本文件改名（如 `宪法-书名.md`），填完第一部分后交 AI 全程遵守；第二部分为固定守则。
> 原则：约束一致性，不束缚发挥。规则只锁两件事——故事世界不跑偏、红线不触碰。
> 修订纪律：任何设定改动，先登记文末《修订记录》再改正文；只改不删。

## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《我爸转世成了我的猫》（工作书名）
- 题材 / 类型：现代都市温情奇幻·主人与宠物灵魂互换（喜剧壳 + 家庭亲情 + 轻悬疑）
- 预计总集数 / 单集字数：约 260 集 / 单集 2200–3000 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：女性向为主 + 全龄温情党；养宠人、亲情向、"先笑后哭"节奏爱好者
- 验收尺子档位：**C 都市言情/情感流档**（情感进展慢、爽点换"情感钩子"；节奏指标按 04-验收清单〇节 C 档执行）
- **一句话差异化**：互换双方是人与宠物（意识互换 + 身体错位喜剧），核心情感是亲情（父子和解）非爱情；与《末世兽语》（人听兽语+异兽团宠冒险）区隔在"住进猫的身体"与"都市日常悬疑"；与《怀表两界》旧版（人换人）区隔在物种错位与催泪浓度。

### 2. 一句话卖点（Logline）
欠租三个月的社恐插画师阮迟，在月圆夜和自家橘猫元宝互换了灵魂——猫穿着他的睡衣给催稿编辑回消息、列还款计划，把他乱成一团的人生捋得井井有条；直到他听见猫对着全家福说人话："迟儿，爸回来了。"

### 3. 世界观设定
- 时间 / 地点：架空现代都市"栖梧市"（虚构城市，不影射真实人物/机构）；老小区出租屋、插画工作室、工地旧档案室三主场。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - **R1 月圆强制互换**：每逢月圆之夜，人与猫互换 24 小时，日出自动换回；双方记忆完整保留，换回后各自疲惫加倍。不可主动发起、不可拒绝。
  - **R2 物种限制**：人身在猫身时无法说话，只能动作、抓字、顶东西传意；猫身在人身时受猫本能干扰（激光笔、鱼腥味、高处癖），暴露风险是喜剧与危机的双重来源。**例外（ep03 补登记）**：转世猫身于非互换期偶可勉强吐出极短人言，全书仅 ep03《全家福》一处刻意为之（"迟儿，爸回来了"），此后不再复用此口子。
  - **R3 心愿强度**：互换时长由"未尽心愿"牵引——心愿越重，月圆互换越提前、越久；心愿了结之日，即互换终止之时（后期解锁，第二幕起生效）。
  - **R4 猫鼻旧影**：猫身可"闻"出某地 24 小时内留下的活动残影（气味记忆），是查旧事的核心能力，也是危险来源。
  - **R5 转世时限**：元宝这具猫身正按"猫寿"倒数衰减（转世身有时限），紧迫感随集数收紧。
  - **R6 单元串长线**：每 2-3 雏一个"人猫协作单元"（赚房租/查旧物/帮邻居），暗线全部串向父亲死因真相（V2）。
- 民俗框架：转世设定走"民间猫有九命"志怪框架的架空演绎，全书内自洽（转世、心愿、时限三规则），不宣传封建迷信，不涉宗教仪式细节。
- 与现实的差异点：仅"月圆互换 + 猫鼻旧影 + 转世时限"三处超自然，其余全写实。

### 4. 核心冲突
- 主角目标：阮迟（查清父亲三年前死亡真相、把烂掉的人生重新立起来）；元宝/阮建国（在时限内替儿子扫清人生障碍、完成未了心愿）。
- 最大障碍：父亲坠楼案的层层遮掩（包工头韩茂灭口式运作）；猫寿时限步步逼近；互换不可控带来的暴露危机。
- 主要对抗关系：阮迟 ↔ 韩茂（真相 vs 灭口）；阮迟 ↔ 自己的摆烂；父与子 ↔ "来不及说出口"的遗憾。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照），并标注视角【迟/猫/双】。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影影。
