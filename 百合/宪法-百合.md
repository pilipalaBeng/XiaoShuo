# 《百合》宪法

> 用法：每开一部新书复制本文件改名（如 `宪法-书名.md`），填完第一部分后交 AI 全程遵守；第二部分为固定守则。
> 原则：约束一致性，不束缚发挥。规则只锁两件事——故事世界不跑偏、红线不触碰。
> 修订纪律：任何设定改动，先登记文末《修订记录》再改正文；只改不删。

## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《撤回键》（工作书名）
- 题材 / 类型：现代都市职场悬疑·双女主纯爱（危机公关 × 调查记者）
- 预计总集数 / 单集字数：约 260 集 / 单集 2200–3000 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：女性向为主，职场博弈、双女主对手戏、敌人到爱人慢燃党
- 验收尺子档位：**C 都市言情/情感流档**（情感进展慢于言情档，爽点换"情感钩子"；节奏指标按 04-验收清单〇节 C 档执行）
- **一句话差异化**：双女主的对手关系由职业本身驱动（一个撤回真相/一个发布真相），冲突不靠误会靠立场；两个完整的人各自有事业线，关系是"对手→并肩"不是依附。

### 2. 一句话卖点（Logline）
危机公关女王程遥的日常工作是把丑闻从热搜上撤下来，调查记者许听澜的工作是把真相顶上去——两人在同一桩上市集团黑幕里反复对线，从互相撬墙角到互相递刀，最后她们一起按下了那颗谁都不敢按的"发布键"。

### 3. 世界观设定
- 时间 / 地点：架空现代都市"临江市"（虚构城市，不影射真实城市/公司/平台/人物）；公关公司与报社双主场。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - **R1 热搜时钟**：一桩舆情事件有"黄金处置期"（24h 冷启动 / 48h 定性 / 72h 收尾），双方所有决策都在时钟里跑——每集自带倒计时张力。
  - **R2 证据链原则**：记者发文须三源交叉验证；公关撤稿只能抓程序漏洞与信息差，不能伪造证据（本书记者、公关操作只作叙事，不写成可操作教程）。
  - **R3 程遥"三不接"**：涉人命的不接、涉孩子的不接、要求毁灭证据的不接——她的职业底线与旧案心结（V1）直接挂钩。
  - **R4 线人分级**：许听澜的线人网络按可信度分 A/B/C 级，A 级一次性，C 级易反水——信息有价，职业有险。
  - **R5 双向卧底**：前期两人各自想从对方身上挖料，酒局递名片、饭局套话——关系张力的引擎。
  - **R6 单元串长线**：每 2-3 集一个舆情单元案，暗线全部串向永昼集团（V7），单元服务长线。
- 与现实的差异点：城市、公司、媒体机构全虚构；行业操作拟真但简化，冲突密度高于现实。

### 4. 核心冲突
- 主角目标：程遥（爬上行业之巅，同时赎早年"洗白案"的罪）；许听澜（挖穿永昼集团黑幕，为被噤声的死者发声）。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照），并标注视角【遥/澜/双】。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影影。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。
- **本书特加合规项**：①双女主纯爱向，无情色描写；②城市/公司/媒体/平台全虚构，不影射真实企业与公众人物；③公关与媒体操作只作叙事与批判呈现，不写成可复制的操作教程；④舆论反转须有道德落脚点，不美化抹平真相的行为；⑤行业细节点到为止，无血腥描写。
