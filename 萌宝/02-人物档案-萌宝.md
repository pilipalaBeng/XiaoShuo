## 二、人物核心卡（静态人设 + 深化补充）

### 【温知意】主角 · 重生宝妈，能听三娃心声

| 字段 | 内容 |
|---|---|
| 身份 | 重生宝妈；前一世独自带三娃累垮、病死病床；重生回累垮次日的医院清晨；能被动听见三萌娃心声（R1） |
| 核心欲望 | 表层：陪三娃好好长大、放下完美主义、守住监护与家；深层：**"这一世别把自己耗干"——重新学会为自己活一点**（第二幕 V9） |
| 致命弱点 | 完美主义焦虑（前世代价）：遇事想"样样做到最好"；**过度自我消耗**（熬夜列计划=旧病复发机制）；心声信息碎片化、误读会错判 |
| 性格标签 | 温柔、会听、"慢半拍"（重生者的克制：不急着追问、先蹲下来）；不骂人但有边界 |
| 成长弧光 | 开场：焦虑妈（累垮前夜） → 中局：会听娃（放下执念、撕计划） → 结局（长线）：松弛妈 → 找回自己（第二幕） |
| 口头禅/标志 | "娘亲在。"；蹲下来与娃平视；先听、后说 |
| 核心关系 | 顾珩/顾梨/顾星（三娃娘，心声接收者）；顾景行（妻）；顾老太君（孙媳）；极品亲戚（对抗） |

**人设深化补充（宪法未写、正文已确立）**
- **"不点破"是她的核心方法**：ep01 发现大宝心声"敲不开"（绷太紧、门关着）不去追问，只把小手捂在掌心——**她的教育观是"等"不是"逼"**。
- **心声是碎片不是读心术**：她听到的是"像从水底飘上来的泡泡"，碎的、片的，三宝最清楚、二宝带哭腔、大宝常常听不到——**R1 的成本在她的挫败感里**。
- **重生者的"慢半拍"**：ep01 明确"前世的她大概会慌、会抓着大宝追问；这一世她不急"——**节奏差是她的成长证据**。

### 【顾珩】大宝 · 7岁小大人

| 字段 | 内容 |
|---|---|
| 身份 | 顾家长子，7岁；表面小大人，背小书包、小脸绷得像小老头 |
| 核心欲望 | 被娘亲**坚定地选**（不是"被留下"，是"被选择"） |
| 致命弱点 | 过早懂事、怕被送走（V2）；**心门关着**——绷得太紧，连心声都"敲不开"；手凉（ep01"七岁的娃，手已经凉成这样了"） |
| 性格标签 | 稳重、吐槽役、沉默的守护者；不闹、不喊困、把书包带子攥到发白 |
| 成长弧光 | 开场：怕被弃的小大人 → ep22 确认"娘不会送走我" → 结局：敢撒娇的孩子 |
| 口头禅/标志 | 抿唇不说话；"我知道。"（ep05 幼儿园局，替娘挡"没爹"的议论） |
| 核心关系 | 温知意（娘，核心）；顾梨/顾星（弟妹）；顾景行（爹，从"陌生人/有刺"到接纳）；顾老太君（祖奶奶） |

**人设深化补充**
- **他的心声"听不到"就是人设**：ep01 温知意屏息等半天"什么都没捞着"——**大宝的封闭不是逆反，是创伤性早熟**。
- **他在替全家撑场面**：ep05 幼儿园局被亲戚呛"没爹的娃没人要"，他的心声是"我知道""娘说爹在"，**站出来替娘说话的是这个7岁的娃**。
- **从"写计划"到"听我"的对照**：ep22 心声"以前娘忙，娘不听，娘写计划；现在娘不写了，娘听，娘抱我"——**他的成长刻度完全由母亲的变化定义**。

### 【顾梨】二宝 · 5岁吃货

| 字段 | 内容 |
|---|---|
| 身份 | 顾家次女，5岁；手里攥着半块没拆的饼干 |
| 核心欲望 | 被看见、有糖（表层"吃" = 深层"被爱"） |
| 致命弱点 | 用吃填缺爱（V3）；**不敢说"我想要"**——把饼干攥软了也舍不得吃 |
| 性格标签 | 软甜、馋、忍着不求人；眼泪在眼眶里打转但不哭出声 |
| 成长弧光 | 开场：偷吃的小孩 → ep04 被递最大块后哭 → ep24 敢说"我想吃" → 结局：敢开口表达 |
| 口头禅/标志 | "梨梨不饿。"；把饼干递出去（"娘吃，娘有力气，娘就不走了"） |
| 核心关系 | 温知意（娘）；顾珩（兄）；顾星（弟）；全家（ep24 抢着给她夹菜） |

**人设深化补充**
- **"饼干"是她的核心意象**：ep01 饿了一早上、饼干攥软了还递给娘——**她的爱是"把自己最缺的给别人"**。
- **抢糖不是馋是求关注**：ep03 温知意第一次没骂她（读懂心声），二宝愣住——**她的问题是"没人看见"，不是"贪吃"**。
- **V3 的回收要走"敢说"**：ep24 敢说"我想吃"是全弧光的落点，不是"戒掉吃"。

### 【顾星】三宝 · 3岁神兽系

| 字段 | 内容 |
|---|---|
| 身份 | 顾家幼子，3岁；趴娘亲胸口哭 |
| 核心欲望 | 被举高高、被夸（表层）；被"看见"（深层） |
| 致命弱点 | **分不清预感真假**（V4）——他的预感是真的，但他不知道怎么说给大人听 |
| 性格标签 | 白切黑、灵、黏人；奶声奶气但心声软软的最清楚；**能提前"感觉"到危险**（ep06 喊"车车来了"提前三秒） |
| 成长弧光 | 开场：被神化的"小神仙" → ep20 被接纳不神化（教他"预感也要说给大人"） → 结局：被接纳的普通孩子 |
| 口头禅/标志 | "娘亲别睡。"；"娘亲香。"（每次被抱都说）；举高高喊"我是小神仙" |
| 核心关系 | 温知意（娘，心声最清楚的接收者）；顾珩/顾梨（兄姐）；顾老太君（"祖奶奶抱星宝"）；顾景行（爹） |

**人设深化补充**
- **三宝的心声是温知意的"信号源"**：ep01 第一声就是『娘亲别睡，星宝怕』——**她是全书第一个"听见"的对象**。
- **预感是"灵"不是"神"**：ep06 提前三秒感知车辆、ep19 躲过小祸，但 ep20 明确"不神化"，教他把预感说给大人——**他的能力必须落地为可沟通的日常**。
- **"香"是他的情感计量单位**：ep01"娘亲身上有药味，但是是娘亲"、ep06"娘亲香"——**他用嗅觉确认"这是安全的人"**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。从已写 32 集正文里提炼的"人物不可越过的线"。

1. **萌宝是娃不是说教者**：三娃台词奶气、有重复、逻辑跳（"娘亲香""他真的煮饭了"），严禁成人化、严禁让娃讲道理讲得比大人清楚（宪法§4 特加红线）。
2. **心声只限三萌娃、只被动接收**：温知意不能听大人、不能主动读取、不能"想听谁听谁"；碎片化、会误读是硬约束（R1）。
3. **亲子信任账户不可崩**：温知意每次"没听见/没回应"都是透支；写冲突后必须有"重新听懂"的修复动作（R4）。
4. **温知意的完美主义是复发型的**：她不是一次性放下（ep14 还会熬夜列计划）——写新集时她遇到压力可以"想再列计划"，但要有"停笔"的自省动作。
5. **顾珩的早熟是创伤不是成熟**：他"懂事"的底色是怕被弃，不得把他写成单纯的乖巧/聪明人设；他的撒娇机会是稀缺资源。
6. **顾梨的"吃"永远指向"被看见"**：不得写成单纯搞笑吃货；每次涉及吃的场景都要能读回"缺爱"层。
7. **顾星的预感不得神化**：他是"灵"不是"神算子"；能力必须落地（说给大人听、被接纳），不得写成开挂预判一切的挂件（ep20 已立此线）。
8. **顾景行不是渣也不许"悔恨卖惨"**：他缺席是替家扛事（V7）；他的回归靠行为补位（学做饭、接手艺），不以痛哭忏悔博取原谅。
9. **顾老太君不写成恶婆婆也不写成工具人**：她的挑剔有来源（旧伤 V5）、转变有触发（热毛巾 ep08）；认孙后就全力护，不再反复无常。
10. **极品亲戚是"明枪型"不是阴毒型**：她敢当众说难听话、教唆会被监控拍到；不得写成擅长设长局的高智商反派（本书反派服务于家庭向基调）。
11. **极品亲戚已退场**：ep17 请出顾家、ep23 信托定、ep29 退群；不得复活为主战场反派，仅可作"闭嘴"式收尾引用。
12. **纯亲情无雌竞不吃感情戏**：不写情色、不写雌竞、不写恋爱救赎；父母感情走清水（宪法§4 特加红线）。
13. **萌娃必须推动事件**：核心矛盾要落在娃能主动推动的节点上（ep05 替娘说话、ep11 心声破案、ep16 齐声表态），大人戏与萌宝日常约 6:4（宪法§4）。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
