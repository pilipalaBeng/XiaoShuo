## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（工作书名）：《听见崽崽的心声后》
- 备选书名：①《三个萌娃团宠我》②《满级奶妈在豪门》③《崽崽心声局》
- 题材 / 类型：萌宝（人形幼崽团宠 + 亲情治愈，轻CP清水）
- 预计总集数 / 单集字数：约 120 集 / 单集 1500–2000 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：18–45 岁女性，爱团宠、萌娃、亲情治愈
- 验收尺子档位：A 短剧爽文档（快节奏；但萌宝戏份须保留"真实萌感"，切忌成人化）

### 2. 一句话卖点（Logline）
> 温知意重生回累垮前夜，意外能听见三个萌娃的心声，她用"读懂孩子"把熊娃养成团宠顶流，也被高冷顾家全员当眼珠子护着——这一世不拼完美，只把亲情缝成铠甲，纯亲情无雌竞。

### 3. 世界观设定
- 时间 / 地点：当代都市，顾家（外冷内热豪门家族）与温知意的小家；纯虚构。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 心声只限三萌娃：主角被动接收，成人听不到（R1）。
  - 团宠公式：萌娃主动推动事件（视角人物非挂件），大人戏6:4（R3）。
  - 亲情为核：冲突落在"护娃/懂娃"，不立恋爱救赎。
- 与现实的差异点：心声为轻幻想设定，其余家庭/职场写实；机构人名虚构。

### 4. 核心冲突
- 主角目标：放下前世完美主义，陪三娃好好长大，守住监护与家。
- 最大障碍：前世执念反噬 + 极品亲戚争监护/信托 + 初期不被老太君认可。
- 主要对抗关系：温知意（全家）vs 极品亲戚；温知意 vs 自身焦虑。

### 6. 核心体系（金手指 / 优势来源，逐条编号）

- **R1 心声聆听**：被动接收三萌娃心声；代价——只能听娃、信息碎片化、误读会错判。
- **R2 科学育儿法**：现代理念（规律作息/正面管教），是认知非金手指。
- **R3 团宠资源网**：顾家全员护娃，反制亲戚；代价——需先赢得老太君认可。
- **R4 亲子信任账户**：每次"听懂"存信任，崩则娃闭心；主角代价节点即透支此账户。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。

### 4. 本书特加红线（差异化契约）
- 萌宝是"视角人物"不是挂件：核心矛盾落娃能主动推动的事件；大人戏与萌宝日常约 6:4（七猫要求）。
- 保留"真实萌感"，切忌成人化台词（萌宝须是娃，不是小大人说教）。
- 纯亲情无雌竞：感情线走清水，不写雌竞/情色（与甜宠言情区隔）。
