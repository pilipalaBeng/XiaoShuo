# 《义庄诡事录》人物档案（僵尸 · 每集更新）

> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。

## 二、人物核心卡（静态人设 + 深化补充）

### 【沈渡】主角 · 末代赶尸匠

| 字段 | 内容 |
|---|---|
| 身份 | 二十四岁，白河义庄新主；沈家赶尸一脉末代传人；沈九山之孙 |
| 核心欲望 | 表层：送每一具无名尸安然归乡；深层：查清祖父死因，弄明白"沈家在守什么"（V1/V3/V6） |
| 致命弱点 | ①阴瞳每用折寿一年（R5，硬代价）；②不擅人情、轴到不肯绕弯（ep11 宁被刀架脖也不破禁忌）；③左腿微跛（阴瞳反噬时从脚踝窜到膝盖） |
| 性格标签 | 寡言、固执、守规矩到轴；**"先镇尸，再问为什么"**——遇事先按规矩做，绝不先问因果 |
| 成长弧光（宪法） | 被动接铃 → 主动扛一脉秘辛；本档案细化为：被动接单的义庄新主 → 开始为自己的判断破例的人 → 愿意为守规矩拿命去换的人 |
| 口头禅/标志 | "规矩你教的，我不破。"；"我在听。"；遇事先抓一把糯米、绕一圈墨线；对棺板低声说话（"爷爷，单是你接的，我送。"） |
| 核心关系 | 阿禾（相依，唯一能懂他沉默的人）；老烟袋（半个师父/消息源）；陆青柏（由疑转信）；黑袍客（死敌）；祖父沈九山（死因与传承的核心） |

**人设深化补充（宪法未写、正文已确立）**
- **规矩是他的语言**：他不安慰人、不解释情绪，只用"按规矩"行动（ep01 对棺板说"单是你接的，我送"；ep11 对兵痞只说"不让"，一字不多）。
- **他会为自己的判断担代价**：ep02 明知"开一次少一年"仍开阴瞳找人；ep11 明知可能死在刀下仍不退——**"守规矩是要拿命去守的"是他本集亲口悟出的第一句人生结论**。
- **对"账"的敏感在生长**：ep04 听老烟袋讲陈四被赖账逼死，他站在堂屋里半天没说话——**他开始意识到"尸"背后都是"人"的债**，这是他将来要替"大冤还债"（V2 赎法）的心理起点。

### 【阿禾】女主级配角 · 义庄哑女帮工 ★本档案新增

| 字段 | 内容 |
|---|---|
| 身份 | 义庄哑女帮工；不能言，通兽语（R9）；眼尾微微往上挑；与密室幼童画像同款眼型（V4） |
| 核心欲望 | 守住义庄这个"家"；守着沈渡（宪法）。深层：她自己尚且不知道的、关于"借嗓之物"的来历（V4） |
| 致命弱点 | 不能言、常被轻视；过度信赖沈渡；**兽语有耗力代价**（ep09 喊完两声腿软、连水都不敢咽） |
| 性格标签 | 安静、敏锐、倔强；**不发人声，只做动作**（拽衣角/按手背/摇头/递符/倒米/喉间低"呜"）；警觉性极高（ep01 先盯院门外动静，ep08 守在暗道口） |
| 成长弧光（宪法） | 从"被收留的哑女" → 义庄真正的主心骨；本档案细化为：→ ep09 兽语显形救人 → 从"守着沈渡"到"能与沈渡并肩出手" |
| 口头禅/标志 | 喉咙里一声很低的"呜"（想说而说不出，或提示危险）；一把桃木符别在腰上；兽牙（ep05 塞给沈渡、ep15 将用以补铃齿） |
| 核心关系 | 沈渡（视之如兄，唯一依靠）；老烟袋（宪法称"孙女"关系）；祖父沈九山（兽语喊的是他小名，V4）；密室幼童（身世线索） |

**人设深化补充**
- **她的"呜"是本书最有效的悬念扬声器**：ep01 院墙根有人走过时"像兽，又赶紧咬住嘴唇"；ep02 死死捂住沈渡的嘴不让他喊；ep04 认出"客"（怨气化形）时"不是吓的，是认出来了"——**她的判断比沈渡更早，只是说不出**。
- **ep09 是她的转折**：第一次"说"出声（以非己之嗓子发尖利鸟声惊退尸群），喊的是沈渡祖父的小名——**她既是救人者，也是谜团本身**。
- **她的动作有强烈的情感功能**：ep05 把兽牙塞进沈渡手心、被退回后又合上手指；ep04 把手按在他手背（掌心也凉）——**她是全书唯一的"温度来源"**，写作时她的每个小动作都该有情绪重量。

### 【老烟袋】核心配角 · 镇上老仵作

| 字段 | 内容 |
|---|---|
| 身份 | 白河镇老仵作，沈渡半个师父；消息最灵通的人 |
| 核心欲望 | 记下白河镇每一桩枉死（宪法）；"讨债的我替你看一眼，账你自己去讨"——只点拨、不代劳 |
| 致命弱点 | 年迈多病，行动受限（宪法）；**知道得太多而不能说透**（白河镇的规矩："别人的账，别瞎问"） |
| 性格标签 | 碎嘴世故、刀子嘴豆腐心；**烟袋锅敲鞋底**是他出场的固定动作；说话半句留半句 |
| 成长弧光（宪法） | 旁观者 → 留下镇志遗稿；本档案细化为：→ ep07 认符一半 → ep09 后被沈渡主动"叫上"（从旁观者转向同行者） |
| 口头禅/标志 | "白河镇的规矩——"；烟袋锅敲鞋底；"我该走了。"（点到即止的退场句） |
| 核心关系 | 沈渡（半个师父，互相依赖）；阿禾（宪法称如祖孙）；黑袍客之符（ep07 一眼认出画法，手抖） |

**人设深化补充**
- **他是"信息闸门"**：ep04 点出陈四与祖父的牵连却不答"为什么"；ep07 认出符的画法却只说"你从哪得来的，就还回哪去"——**他的克制本身是剧情节拍器**（悬念不能一次给完）。
- **他的世故里有敬畏**：ep07 讲"北边来的人"二十年前夜行昼伏、只用黑得发亮的东西画符时，手先抖了一下才说——**他不是不怕，是见得多**。

### 【陆青柏】核心配角 · 年轻军阀副官

| 字段 | 内容 |
|---|---|
| 身份 | 二十七岁，镇外军营副官；十八岁当兵，打了十年仗；陆家族谱二十年前丢失 |
| 核心欲望 | 寻回陆家族谱信物（宪法）；**隐藏欲望：查清西边工事到底在干什么**（ep11 起显形） |
| 致命弱点 | 立场夹在军令与良知之间（宪法）；**他的兵会背着他作恶**（ep11 兵痞翻尸，他事后才知道） |
| 性格标签 | 体面、克制、重诺；**眼睛很亮、话少但每句有分量**；不用官威压人（ep10 给沈渡倒水的是沈渡，他只把碗放着不喝） |
| 成长弧光（宪法） | 工具人军官 → 自主选择者；本档案细化为：→ ep10 承认"我得把他当阵亡抬回来"（第一次说破军中黑幕） → ep11 重处置兵痞并道歉（**良知开始压过军令**） |
| 口头禅/标志 | "沈相公。"（固定的敬称）；"昨夜的事，对不住。"（不推责的道歉）；始终把刀挎在腰上但从不拔 |
| 核心关系 | 沈渡（由疑转信，ep10 起）；他的兵（控制力有限的部下）；黑袍客/军中黑产（潜在对立面，V7） |

**人设深化补充**
- **他是"体制内的良知样本"**：ep10 明知第三具尸不是阵亡仍要按阵亡抬回（"可我必须把他当阵亡抬回来"）——**他在规则与人情之间做的是"先按规则办事，再私下查真"的双线操作**。
- **他的克制与沈渡的轴形成对照**：沈渡为规矩硬扛刀，陆青柏为查真相隐忍——**两个都是守规矩的人，一个守民俗、一个守军令**，这是 ep27"沈陆两家本是守封印同盟"（V8）的人物基础。
- **ep10 那句"西边工事不干净，你最好别去"**是他第一次向沈渡递出善意，也是他"不只是来寻族谱"的第一个证据。

### 【黑袍客】主线反派 · 邪术士（沈家叛出师叔）

| 字段 | 内容 |
|---|---|
| 身份 | 神秘邪术士，盗墓军阀幕僚（宪法）；沈家叛出的师叔（V6/ep25 揭示，**揭晓前只用"黑袍客"**） |
| 核心欲望 | 集齐不化骨以"逆死为生"（宪法）；夺封印钥匙（含玉佩半块 + 沈渡阴瞳，V5/V2） |
| 致命弱点 | 逆术反噬，需不断补"阴料"（宪法）；**他的符会自作主张地救沈渡**（ep11 发热挡刀，暗示他需要沈渡活着） |
| 性格标签 | 温润阴鸷、目的至上（宪法）；**never 露面**（ep14 前）——通过"符/黑光/北边来的人"间接出场 |
| 成长弧光（宪法） | 执念者 → 被自身术法吞没；本档案细化为：→ ep06 其符首次出现 → ep11 借符救沈渡（第一次"打交道"，交易意味不明） |
| 口头禅/标志 | 黄纸黑墨的符（画一个头尾缠在一起的盘状东西）；那种"湿土又像旧血"的墨味；黑得发亮的光 |
| 核心关系 | 沈渡（宿敌，但 ep11 后多了一层"欠一命"的纠缠）；胡掌柜（符的流出渠道）；军中黑产（其阴料来源，V7） |

**人设深化补充**
- **他的出场设计是"符先行"**：ep06 符从胡掌柜袖中搜出 → ep07 老烟袋认出"北边来的人"的画法 → ep11 符发热替沈渡挡刀——**人在 ep14 才露面，但符已经替他演了三集戏**。
- **ep11 的"救"是全书最关键的灰度笔触**：他为什么要救沈渡？是交易、是投资、还是"钥匙不能死"？**写作时必须保持这个不明——禁止提前给动机**。
- **兵痞认得那种黑**（"在西边工事那边见过"）——**他的术法与西边工事/阴泥源头是同一根线**（V8/R8）。

### 【沈九山】主线暗线 · 沈渡祖父 ★本档案新增

| 字段 | 内容 |
|---|---|
| 身份 | 白河义庄前主，沈渡祖父；头七夜前七日去世；临终只挤出"铃，别……"三字 |
| 核心欲望 | 守封印、把一脉秘术与责任传给孙子（宪法隐含：为封印黑袍客夺钥自断一臂而亡，V1） |
| 致命弱点 | 已故；**他留下的信息全是"半句"**（"这铃少一齿，日后……"未竟；"土里的东西，沾上身，就不是你的了"没头没尾） |
| 性格标签 | 严厉、沉默、有话不说透；教孙子的方式是"抽着背书"和"用烟袋锅指地" |
| 成长弧光 | 已完成（前史：为封印黑袍客夺钥、自断一臂而亡，V1/ep28） |
| 核心关系 | 沈渡（祖父/传承核心）；阿禾（兽语喊他小名，V4）；黑袍客（当年的对手/可能的同门）；不化骨封印（他守的东西） |

**人设深化补充**
- **他是"谜团型亡者"**：宪法要求"已退场角色不得复活"，他的功能是**情感锚点 + 悬疑发动机**——他留下的每一个物件（玉佩、缺齿铜铃、半本《赶尸册》、密室）都是一个待解伏笔。
- **他的"拒收单"是全书的第一条暗线**：ep02 揭示他生前拒收过三桩失踪者的单，ep04 老烟袋点出他拒收陈四带账的单——**他拒收的不是尸，是"账"**（"有些账，赶尸匠不能带。"）——这条线直通 ep28 他的死因。

### 【紫僵（货郎陈四）】单元尸 · 怨气化形债主 ★本档案新增

| 字段 | 内容 |
|---|---|
| 身份 | 青石镇人，跑德昌号货的货郎；被胡掌柜赖账逼死；死后为紫僵，掌中攥祖父半块玉佩；怨气可化形 |
| 核心欲望 | 讨回被赖的账（"讨到自散，讨不到长守"，R6）；点出德昌号 |
| 致命弱点 | 怨气化形"不能跟它打"（一打就变煞，R6）；只能指方向，不能自己讨 |
| 性格标签 | 无脸的灰、离地半寸、"不害人不追人，只讨债"；转脸朝德的姿势是它的"语言" |
| 成长弧光 | 已交接青石镇同行（ep04）；怨气化形后指东墙（德昌号），逐步压淡 |
| 核心关系 | 沈渡（送尸者/代讨者）；胡掌柜（债主）；祖父沈九山（当年拒收其单） |

**人设深化补充**
- **它是全书第一个"账"的具象化**：ep04 它没有脸、不说话、只"指"——**怨气化形是本书对"人死账未清"的视觉化处理**，写作时它不该有任何情绪表演，只有方向。
- **它的存在定义了本书的核心命题**：尸不是敌人，债才是。

### 【胡掌柜 / 胡大郎】灰度角色 + 配角 · 德昌号

| 字段 | 内容 |
|---|---|
| 身份 | 胡掌柜：白河镇东大商户德昌号掌柜，赖账逼死陈四；胡大郎：其子，诈死局同谋 |
| 核心欲望 | 吞产（诈死脱身）、保住德昌号的账 |

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从已写 11 集正文里提炼的"人物不可越过的线"。

1. **沈渡不解释、不安慰、不抒情**：他用动作和规矩说话（"规矩你教的，我不破。"），**禁止让他讲人生大道理或长篇感悟**；情绪必须落在"抓糯米/绕墨线/看棺板"这类动作上。
2. **阴瞳（R5）是硬代价，不是外挂**：开一次折寿一年，反噬必须写"脑中一扎+鼻血+左腿从脚踝麻到膝盖"。**禁止"该开就开"**——每一集开眼前，他必须先在"值不值得"上纠结（ep04 明写"我的寿数，得留着去敲德昌号那扇门"）。
3. **沈渡守规矩，但不拿规矩杀人**：他会硬扛刀（ep11），也会放胡掌柜生路（ep06）——**"守规矩"不等于"死板"，更不等于"冷酷"**，他是有底线的轴。
4. **阿禾绝不说话（人话）**：全书她**只能通过动作/眼神/喉间低"呜"/兽语**表达；**禁止为方便剧情让她写字条、点头代替长篇回应**。兽语（R9）每次使用必须有耗力代价（腿软/嗓子哑/后续几集失声）。
5. **阿禾的判断永远比沈渡早**：她是"说不出话的预警器"——写危险逼近时，**第一个有反应的人应该是她**（ep01/02/04 都是这个模式）。
6. **老烟袋只给半句，不解释透**：他的功能是制造悬念节奏，**禁止让他一次把案情/伏笔讲完**；退场固定用"我该走了。/白河镇的规矩——"；烟袋锅敲鞋底不可省。
7. **陆青柏体面、克制、不摆官威**：他道歉（ep11）、他承认军中黑幕（ep10）——**禁止把他写成仗势欺人的军阀痞子**；他的刀挎着但从不拔。
8. **黑袍客在 ep14 前绝不露面**：只能通过"符/黑光/北边来的人/墨味"间接出场；**禁止提前给动机、身份、台词**（ep25 才揭"沈家叛出师叔"）。
9. **黑袍客之符的"救"必须保持不明**：ep11 它救了沈渡，**原因不得解释**——它是悬念，不是道具福利。
10. **沈九山已故**：不得复活、不得以长篇回忆滥用；他只能通过**物件（玉佩/铜铃/册子/密室）+ 半句遗言 + 他人转述**存在。
11. **怨气化形（R6）是"账"的具象**：可以指方向，**不能打、不能对话、不能有情绪表演**——它是一团没有脸的灰（一打就变煞，这是设定红线）。
12. **阴泥（R8）的"三宝失灵"必须写实**：糯米不黑、墨线缠不住、符贴不上——**禁止偷偷让三宝生效**（否则 ep09 的危机与 ep07 的设定全部作废）。
13. **民俗设定一律以志怪框架呈现**：宪法 §3 与 §3-合规项要求——**不直给、不宣扬封建迷信**，恐怖走悬疑感、血腥点到为止。
14. **"账"是本书唯一的核心命题**：写任何单元案子，都必须能回答"这桩尸/这桩怨，欠的是谁的账"——**这是本档最不可丢的人物质感**。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字：沈渡/阿禾/老烟袋/陆青柏/黑袍客/沈九山）
4. **伏笔纪律**：本档案对 V1–V8 只记"人物侧"变化（谁知道了什么），**伏笔状态以《伏笔活表-僵尸.md》为准，本档案不维护伏笔表**。
5. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定（尤其祖父死因、阿禾身世、黑袍客身份）。
