# 《僵尸》宪法

> 用法：每开一部新书复制本文件改名（如 `宪法-书名.md`），填完第一部分后交 AI 全程遵守；第二部分为固定守则。
> 原则：约束一致性，不束缚发挥。规则只锁两件事——故事世界不跑偏、红线不触碰。
> 修订纪律：任何设定改动，先登记文末《修订记录》再改正文；只改不删。

## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《义庄诡事录》（工作书名）
- 题材 / 类型：中式民俗僵尸·志怪单元剧
- 预计总集数 / 单集字数：约 300 集 / 单集 2200–3000 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：18+ 中式怪谈、民俗志异、单元探案爱好者
- 验收尺子档位：**B 规则怪谈/无限流档**（民俗禁忌即"硬规则"，违反即出事；节奏指标按 04-验收清单〇节 B 档执行）

### 2. 一句话卖点（Logline）
末代赶尸匠守着一脉千年秘术，一程程送不甘的尸首归乡，才发觉每只僵尸生前都欠着一桩没还清的人债——而他祖父的死，正卡在这笔总账里。

### 3. 世界观设定
- 时间 / 地点：民国初年（约 1917 年），湘西边地「白河镇」及沿途村寨、义庄、古道。军阀混战、火车刚通、旧行当末路。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 本书为**民间志怪框架**——僵尸现象以「民俗方志成因体系」作内解释（考据自《阅微草堂笔记》《子不语》等志怪典籍的民间说法），读者当以民间传说视之，**非现实科学论述，亦非宣扬封建迷信**。
  - 赶尸行当有严格「规矩」，民俗禁忌即本书的"规则怪谈"本体；规矩被破=风险兑现。
  - 僵尸按怨气深浅与尸身腐变分六阶（见核心体系 R3），越阶越难送、越凶。
- 与现实的差异点：存在"阴瞳""尸气""镇尸三宝"等志怪设定，但皆有民俗出处与内部自洽因果，不引入现代科技解释。

### 4. 核心冲突
- 主角目标：送每一具无名尸安然归乡，并查清祖父沈九山死因。
- 最大障碍：千年"不化骨"封印松动，多方势力觊觎；自身阴瞳反噬折寿。
- 主要对抗关系：沈渡（守序送尸）↔ 黑袍客（夺不化骨）↔ 时代洪流（军阀毁坟、铁路破风水）。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。
- **本书特加合规项**：恐怖氛围走悬疑感路线，血腥细节点到为止；民俗设定一律以志怪框架呈现，不直给、不宣扬封建迷信。

## 使用说明

1. **写每一集前**，先读：①本文件（世界观/人物卡/当集大纲/设定库）→ ②《**小说写作通用规则.md**》（跨书铁律与自查清单，处理标点/句式/词汇）→ ③《**02-人物档案-僵尸.md**》的"成长轨迹线 + 关系网 + 写作红线"三区（人物连续性以该档案为准）。
2. **写作铁律**：标点 A 类是机械必检项（引号成对、禁 `""` 连排、破折号 ≤2），A 类未清零不得送审；完整 B/C/D/E 类条款见《小说写作通用规则.md》。
3. 剧情调整（改结局/加人物/改规则）先更新本文件，再续写，防漂移。**新增人物须同步在《02-人物档案-僵尸.md》建卡。**
4. **每集写完后**：向《02-人物档案-僵尸.md》追加本集成长轨迹锚点（只增不删）+ 更新关系网。
