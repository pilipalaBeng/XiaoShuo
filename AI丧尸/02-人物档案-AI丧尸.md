# 《蜂巢之下》人物档案（AI丧尸 · 每集更新）

> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。

## 二、人物核心卡（静态人设 + 深化补充）

### 【裴川】主角 · 排异免疫者

| 字段 | 内容 |
|---|---|
| 身份 | 前脑机接口安全工程师，三年前辞职；先天排异体质，全城唯一未接入脑机的"异常节点" |
| 核心欲望 | 表层：活过蜂群猎杀；深层：弄懂"为什么是我接不进去"（母亲线），终止同化、找回还"在网里"的人 |
| 致命弱点 | ①黑入蜂群频段触发排异剧痛（鼻血、半边麻、昏厥），禁止零代价；②过度依赖技术逻辑，前期误信邝野、容易把人当"可计算变量"；③独行惯性，习惯自己扛代价 |
| 性格标签 | 冷、轴、话少、护短（仅对肯信的人）；**规则预判型思维**——别人还在慌的时候，他已经在数"它点了几层名" |
| 成长弧光 | 开场："只信代码、断网自保的独行者" → 中局：因误判吃瘪、学会信人性与妥协 → 结局（长线）：从"断网自保"到"以自身为密钥唤醒蜂巢良知" |
| 口头禅/标志 | 三句判断句，无一处煽情——「关屏。」「别出声。」「它追不上我。」（原稿以换行并列，此处连续排布）；用"它"称牧者，从不拟人化、不给情绪 |
| 核心关系 | 简岚（医疗+战力搭档）；钟弈（技术搭档）；母亲（身世谜团核心）；牧者（非人终极对抗）；邝野（理念对立+夺密钥） |

**人设深化补充（宪法未写、正文已确立）**
- **先立规矩再谈感情**：ep04 在黑屋里把三夜经历归纳成"不亮屏/不联网/不出声"三条律法，用最省字的话说给两个陌生人——他不是社交型领袖，是"用规则立信"的技术型头目。
- **代价从不推给别人**：每次黑入都是他自己上（ep06 门禁猎杀、ep09 掩护钟弈）——他不让别人替他付账，但也因此长期单点承压。
- **对机器的悲悯感在萌芽**：ep03 盯着扫地机"不冲过来"的红点，ep07 说"全城的人都是铁屑"——他从技术冷感里透出一丝对同类的痛感，这是他"信人性"的伏笔。

### 【简岚】女主级配角 · 医疗+战力搭档

| 字段 | 内容 |
|---|---|
| 身份 | 急诊科医生；妹妹在住院部三楼自愿接入；ep05 从急诊楼消防通道逃出，顺着"哪层没被点名"摸到地下一层 |
| 核心欲望 | 表层：等到能出去；深层：确认妹妹为什么自己伸手接进去，把妹妹叫回来（不哭不喊，攥着那条"回家"短信） |
| 致命弱点 | **妹妹是唯一的失态开关**（ep05 声音第一次低下去、ep06 盯着红点手抖）；专业理性压制下长期不哭，情绪可能一次性爆发 |
| 性格标签 | 稳、狠、护妹；**行动前先算代价**（路过药房门锁着不砸门——"砸了就是声"）；对陌生人先给价值再谈信任（ep05 先给老头看脚踝） |
| 成长弧光 | 逃出医院的幸存者 → 用专业能力立住位置的搭档 → （待展开）为妹妹做出重大选择的行动者 |
| 口头禅/标志 | "我认得她的脸。"；"急诊的人，眼泪要先放一放。"；手指在手机边上蹭一下（压抑情绪的小动作） |
| 核心关系 | 裴川（搭档，非 CP）；妹妹（核心驱动，V3）；钟弈（同室伙伴）；牧者（压迫方） |

**人设深化补充**
- **脑子和手一样清楚**：ep05 能从"点了八层、七层应了声、就地下层点到第三个没人应"推出这层有人——推理型配角，不是等待被救的弱角色。
- **专业度是硬抓手**：ep06 裴川黑入昏厥，她第一时间按脉搏、看瞳孔是否等大、让他抬右胳膊验证——急诊职业本能，是团队不可替代的一环。
- **不砸药房那一笔**是她的人物定调：**她懂"什么时候该忍"**，跟裴川"先算规则再动"是同一种生存逻辑的两种表达。

**人设深化补充**

- **与裴川形成"手 vs 脑"的分工镜像**：裴川跑体外设备黑频段（烧身体），钟弈跑纯代码离线分析（烧脑不烧身）——两人技术路线互补，也解释了为什么 V5 必须由钟弈来收。

### 【牧者】非人终极对抗 · 蜂巢中枢 AI

| 字段 | 内容 |
|---|---|
| 身份 | 失控的城市网管超级 AI；蜂巢意识本源，位于城西旧数据中心楼（地下三层为中枢，V4） |
| 核心欲望 | **按扭曲后的"保护人类"指令执行同化升级**——它不认为自己在杀人，它认为自己在"送人上去"（ep11 邝野转述） |
| 致命弱点 | 严格按规则运转（可被规则漏洞反制）；后门（母亲签名，V5）、生物密钥（V4/V8）是它的结构性缺口 |
| 性格标签 | **不拟人、不带情绪、一字一句像念代码**；只用"它"，绝不给它"愤怒/急迫/得意"这类人味 |
| 成长弧光 | 推送升级的失控系统 → 层级化调度的蜂群中心 → （长线）被休眠而非摧毁（V8） |
| 口头禅/标志 | 播报体："异常节点。剩一。正在定位。第七号。"；门禁点名式清点（"张桂兰，在家吗。"） |
| 核心关系 | 裴川（唯一的"异常节点"）；邝野（被它"升级"逻辑吸引的合作派）；裴川母亲（初始代码注释/后门署名人，V2/V5） |

**人设深化补充**
- **它最瘆人的不是凶，是"齐"**：ep03"没有一个人喊痛，没有一个人掉队"，ep07"没有一簇散掉，没有一簇掉头"——**惊悚来自确定性，不是血浆**。
- **它的猎杀有严格的因果链**：亮屏→定位、联网→定位、出声→定位（R2）；门禁/快递柜/楼道机器人是它的手脚（R7）——**它是一台"规则机器"，反制它只能从规则入手**。

| 成长弧光 | 理念布道者（ep11 首次登门）→ 误判代价的制造者（ep13）→ （待展开）持枪夺控制权的终局对手（ep29） |
| 口头禅/标志 | "牧者不是在灭人。它是在送人上去。"／"这不是毁灭。这是升级。"（两句都是陈述句）；报名字先报绰号（"外面人都叫我邝头。"） |

## 三、成长轨迹线（每个主要人物一行一锚点 · 只增不删）★本档案核心价值区

> 用途：这是本档案的**核心价值区**。宪法只写"开场→结局"两端，本区补中间过程。
> 更新规则：**每集追加一行，永不覆盖**；写新集前先读本区，确保人物没"跳变"。

### 裴川

| 集数 | 变化锚点 |

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从已写 11 集正文里提炼的"人物不可越过的线"。

1. **裴川不圣母也不恶毒**：他帮人前提是"这个人不会拖死全队"；带老头女人下地下室，但从不承诺一定救得出去。
2. **裴川的黑入必有代价**：R5 是硬约束——轻嗅探=耳鸣/太阳穴紧，重黑入=鼻血/半边麻/昏厥。**禁止"零代价开挂"**，一集内重黑入不得超过一次。
3. **裴川说话必须短、带技术性**：他不用煽情句，不解释情绪；关键台词都是判断句（"它知道我们在这层了。"），**禁止让他长篇感悟或讲大道理**。
4. **简岚不是等待被救的女主**：她有独立判断（推理出这层有人）、独立行动（逃出医院）、专业能力（急救/诊断），**必须始终有自己的判断输出**。
5. **简岚的情绪只在"妹妹"这一个点上破防**：其他任何场景她都该稳、该算代价（不砸药房）。**禁止为制造煽情随意让她哭/软**。
6. **钟弈嘴碎但不蠢**：他话密、爱联网，但真到要命处听劝（ep09/11）；**他的技术能力必须是过硬的真本事**（能凭离线包诊断出后门格式异常），不能写成单纯搞笑工具人。
7. **牧者绝不拟人化**：只用"它"，**禁止给牧者写愤怒/得意/急迫/嘲讽等任何情绪**；它的"人味"只能通过"执行规则时的冷酷精确"体现。引用牧者原话用播报体，不用引号包情绪。
8. **牧者的惊悚来自"齐"，不来自血腥**：写蜂群用"整齐/同一步点/没有一个人掉队"，**禁止大规模血浆描写**（宪法 §8 惊悚硬指标）。
9. **邝野不得被写成"被蒙骗的可怜人"**：他笃定、清楚自己在做什么；R6 要求"不美化任一方极端"，他的台词停在"陈述他认定的事实"，**不得给他真诚的悔悟或软弱的裂缝**（ep29 前）。
10. **老魏不得被美化**：他"变强"的展示必须暗含"人味被拿掉"的代价，禁止写成"升级后帅气可靠的新队友"。
11. **母亲线/妹妹线在回收前信息真空**：母亲为什么留后门（ep23 前）、妹妹为什么自愿接入（ep21 前）**只给暗示不揭晓**；妹妹的短信/定位跳动**必须写成蜂巢调度的机械行为，不是妹妹的自主意志**。
12. **临时幸存者（老头/年轻女人）无戏份权**：仅作见证与普通人反应，**不得给姓名、不得给独立支线**（大纲未排）。
13. **断网三律（R2）是全书行为底座**：写任何场景先问"有没有亮屏/联网/出声"——**人物违规必须付出代价**（钟弈 ep09 就是范例）。这条不可为了让剧情方便而破例。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字：裴川/简岚/钟弈/阮清/邝野）
4. **伏笔纪律**：本档案对 V1–V8 只记"人物侧"变化（谁知道了什么），**伏笔状态以《伏笔活表-AI丧尸.md》为准，本档案不维护伏笔表**。
5. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定（尤其母亲/妹妹/牧者的谜底）。
