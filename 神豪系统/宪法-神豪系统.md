## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《神豪：花钱就能变强》（工作书名）
- 题材 / 类型：神豪系统（男频·金钱爽感向；差异化：财富自由度碾压是爽点，但设"消费KPI惩罚"隐性约束，并叠加"实业成长+系统来源暗线"双引擎，拒绝无脑撒币）
- 预计总集数 / 单集字数：约 300 集 / 单集 1500-2200 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：男频 18-35 岁，偏好"花钱爽、数字爽、反转快"的系统流读者
- 验收尺子档位：A 短剧爽文档（节奏指标按 04-验收清单〇节该档替换）

### 2. 一句话卖点（Logline）
被裁员当天的贺衍激活"神豪系统"：每月必须花光定额，否则扣减生命值——他一边用"消费返利"把花钱变成印钱，一边盘下亏本实业练手、查清系统究竟是谁留给他的；可越是炫耀，越把富二代邵天阔和一场绑架引到了头上。

### 3. 世界观设定
- 时间 / 地点：当代都市观澜市，存在神秘"神豪系统"（超自然金手指，来源成暗线）。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - R1 消费返利：花出去的钱按规则返还（基础 100%，任务加成更高），"花钱=变强"的引擎。
  - R2 月度消费 KPI：每月须花光系统定额，否则扣减生命值（隐性约束，制造张力）。
  - R3 资产确权：系统钱买来的资产须合规登记，越线（洗钱/违法）触发系统封禁。
  - R4 利他任务：系统不定期发布"做一件利他消费"任务，完成后解锁新功能（暗线：系统有价值观与旧主人）。
- 与现实的差异点：系统资金真实可花、返利真实可增，但受 KPI 与确权双约束，非无代价印钞机。

### 4. 核心冲突
- 主角目标：用系统钱解决困境、守护妹妹、把实业做成事业、查清系统来源。
- 最大障碍：消费 KPI 的时间/生命压力；富二代邵天阔的针对；系统来源暗藏危险。
- 主要对抗关系：贺衍 vs 邵天阔/邵家（明面） vs 系统来源暗线中的"旧主人遗留局"（暗面） vs 自我"炫耀招祸"的弱点。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节（洗钱/逃税）、真实人物影射。
- 价值观：不美化犯罪；花钱须合规（R3 资产确权），反转有道德落脚点（利他任务 V8）。
- 平台规则变更时，以最新投稿规范为准。

1. **写每一集前**，先读：①本文件（世界观/人物卡/当集大纲/设定库）→ ②《**小说写作通用规则.md**》（跨书铁律与自查清单，处理标点/句式/词汇）→ ③《**02-人物档案-神豪系统.md**》的"成长轨迹线 + 关系网 + 写作红线"三区（人物连续性以该档案为准）。

4. **每集写完后**：向《02-人物档案-神豪系统.md》追加本集成长轨迹锚点（只增不删）+ 更新关系网。
