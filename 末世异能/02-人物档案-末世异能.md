## 二、人物核心卡（静态人设 + 深化补充）

### 【江烬】主角 · 余温系觉醒者

| 字段 | 内容 |
|---|---|
| 身份 | 灾前冷链物流调度员（懂低温、仓储、物资调度），冷库待了六年；灾变夜被困冷库却未冻死；灾后"余温系"觉醒者（灰核现状） |
| 核心欲望 | 表层：找回被暖巢掳走的妹妹江熹、给自己和身边人一处不被冻死的安全屋；深层：弄清"我为什么没死在冷库"（V6） |
| 致命弱点 | **暖核反噬**：全力出手后身体某处永久冻僵（右小指已冻枯、左手腕冻乌半废）；**过度算计、不信任他人**，前期多次因误判付出代价（ep09 追旧脚印坠废井） |
| 性格标签 | 冷静、记仇、护短、嘴硬；**先算后动**（盘点货、估步速、算"撑不过明天中午"）；**对物品舍不得**（舍不下码好的货） |
| 成长弧光 | 开场：独善其身的利己者（"帮人是要还的，他知道"）→ 从救邵凛开始学着给人 → 会自省（ep09"想她，也得先活着"）→ 结局：以暖核过载换永冬松动 |
| 口头禅/标志 | "数完再说。"；短句、动作先行；轴式自问自答；小太阳插头、扳手、工牌、红围巾（江熹的，收怀里） |
| 核心关系 | 江熹（软肋/核心驱动）；邵凛（生死搭档）；温姨（后勤核心/清醒剂）；陆衡（理念对立） |

**人设深化补充（宪法未写、正文已确立）**
- **他的"利己"是活下来的本能，不是恶**：ep05 他攥着扳手准备关门"他只要把门一关，这个人就倒在楼道里，他的货照样是他的。他一贯是这么干的"——放手让他救邵凛的不是心软，是**"他想起河面上那几个小时，冷到骨头里，没人来拉他一把"**。
- **他的技能全是"冷库经验"**：ep01 数货、摸管、认异响，"这台冷库他待了六年，哪根管子漏氟，哪个风机异响，他闭着眼都摸得到"；ep04 扫空商铺建物资点也靠这套。写他的"生存能力"必须落在冷链专业细节上。
- **他的痛都藏在"藏"里**：ep05 给邵凛焐热后"把左小臂藏到身后，不让他看"；ep09 把手贴脸一会儿又拿开。**他做善事的第一反应是不让人看见**。
- **他会犯执念型错误**：ep09 半截红围巾让他"忍不住"，顺旧脚印跑了百米、坠井、多抽一把热、灰核又浅一层——**"妹妹"是他唯一的失态开关**。
- **他不是冷血，是怕还人情**："帮人是要还的，他知道"（ep05）——他的防备来自"欠人情"的负担，写他接受帮助时要写出别扭。

### 【邵凛】第二男主级配角 · 霜蚀系觉醒者

| 字段 | 内容 |
|---|---|
| 身份 | 前消防员，霜蚀系觉醒者；从暖巢核炉跑出来（被追三天）；江烬的生死搭档 |
| 核心欲望 | 替亡队还债、护住活人（"替亡队还债"是他自述的动机） |
| 致命弱点 | **旧霜蚀反噬伤**（V4）：忌寒，"我这伤是老毛病"、"老伤，提它没用"；失控时会变成"要把我冻死"的状态 |
| 性格标签 | 热血、轴、听劝；**"有些伤，他不用问"的分寸感**；判断冷静（"这脚印太旧，追不上"） |
| 成长弧光 | ep04 破门求救的濒死者 → 与江烬结伴 → 为救他暴露霜蚀底牌（ep16 计划）→ 旧伤爆发命悬一线（ep17 计划）→ 被秘药救回（ep20 计划） |
| 口头禅/标志 | "我冷。"；"走不走。"；短句、实；「消防队」三个字会顿一下 |
| 核心关系 | 江烬（生死搭档，救命与被救）；温姨（同队）；暖巢（从核炉逃出、被追捕方） |

**人设深化补充**
- **他和江烬是"同构的痛"**：ep05 两人互相看出对方"藏着伤"——"你也是能带热的"、"你也够烫的。和我一样"，**两个人都不问对方的伤**。这份"不问"是他们信任的起点。
- **他更懂"活下来"的次序**：ep09 他拉江烬"别追。这脚印不是新的。她不在这条道上"，是队里给江烬降温的人（与温姨分工：他拦行动，温姨讲道理）。
- **他的信息是暖巢线的入口**：ep05 他交代"暖巢在抓人…抓能带热的人，像你，像我。抓到城北去，送进核炉里。我就是从那儿跑出来的"——**他是暖巢真相的第一手情报源**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从 ep01–ep09 正文里提炼的"人物不可越过的线"。

1. **江烬利己但不冷血**：他可以准备关门自保，但**最终的选择必须落在"他自己冻过、记得那种滋味"上**，不能凭空善良，也不能真见死不救。
2. **江烬的善举第一反应是"藏"**：帮完人立刻把伤藏起来（ep05 藏左臂）、不让人看见——写他"邀功式善良"即 OOC。
3. **暖核是限制器，不是外挂**（R3）：每次过载必须付出可见代价（冻枯/灰核变浅），**禁止零代价爆发**；代价进度要与状态库一致（右小指→左手腕→掌心磨破→灰核更浅）。
4. **江烬的生存技能必须落在"冷链专业"上**：数货、估步速、认异响、融冻路——**写他"全能生存专家"而不给专业依据即 OOC**。
5. **"妹妹"是江烬唯一的失态开关**：他会因此犯执念型错误（ep09 坠井），但**每次失态后必须有队伍拉回 + 他自己认账的过程**，不能连续犯同一个错。
6. **江烬接受帮助时会别扭**："帮人是要还的"是他的负担感；写他坦然受助即 OOC。
7. **邵凛克制、有分寸**：他的判断冷静、话短、不问别人的伤；写他话痨或情绪化即 OOC。
8. **邵凛的旧伤是"定时炸弹"**（V4）：不得提前治愈，爆发排期 ep17；他的霜蚀失控需要"忌寒"的物理表现。
9. **温姨不指责、只拉人**：她的作用是把主角拽回"活下来"的序列；写她刻薄或说教即 OOC。
10. **江熹必须以"物"存在**：短袖外套、塑料别针、红围巾——**至今不给她正面戏**；围巾的细节（针脚/烟头洞/污渍）是可信度来源，不可省略。
11. **红围巾不等于"她在这里"**（ep09 关键）：物件只证明她"来过"，写主角靠围巾直接定位她是 OOC。
12. **陆衡在 ep12 前只给暗示、不揭晓**（宪法排期）：广播/传闻/追捕者可以出现，**不得提前填充他的身份、动机、长相**。
13. **尸潮不是丧尸**（R6 划界）：非病毒、可被余温净化；**禁止咬人变异、爆头、病毒感染等丧尸套话**。
14. **对白短句 ≤20 字、动作推进优先**：这是 A 档要求；江烬/邵凛尽量极少台词，温姨台词也必须短。
15. **双线每集各推进一处**：生存压力线（冷/饿/物资）与能力成长线（暖核升温/代价）——缺一条即不合格。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5/§6 = 静态人设与分集大纲（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
5. **人名以《术语表-末世异能》为准**：江烬（非江尽/姜烬）、江熹（非江喜/姜熹）、邵凛（非邵林/邵麟）、温姨、陆衡（非陆恒/陆珩）；名词：暖核（非温核）、余温系（非余热系）、霜蚀系（非冰系）、寒蚀（非反噬冻伤）、尸潮（非冰尸/冻尸群）。
