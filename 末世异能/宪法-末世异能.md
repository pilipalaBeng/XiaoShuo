### 2. 一句话卖点（Logline）
> 极寒永冬里，冷链调度员江烬靠体内觉醒的"暖核"异能一层层升温进阶，在冻死边缘囤出安全屋、找回被掳走的妹妹——可每一次火力全开，身体就多一块永远冻僵。

### 2b. 一句话差异化（★明确写入，四书不得撞车）
> **末世异能 = 细分天灾（极寒永冬）+ 异能升级体系**：敌人在环境与人性，不在丧尸；爽点来自"囤货写实清单 × 暖核升温进阶"双轨，而非基建或科技恐慌。

### 3. 世界观设定
- **时间 / 地点**：近未来架空，"大寒"灾变后第三年；故事起于北纬寒区某座被冰封的工业城（不对应任何真实国家/城市，统称"凛城"）。
- **核心规则（力量体系 / 社会规则 / 独特设定）**：
  - 灾变：全球气温在 72 小时内断崖跌至 -40℃ 以下并持续下行，进入"永冬"。原因不明（伏笔 V1）。
  - 暖核：极寒中濒死情绪峰值者"觉醒"，体内生成"暖核"——异能之源，温度越高能力越强。
  - 反噬：异能输出超过暖核当前容量，施术者被自身"寒蚀"反咬，局部冻伤乃至永久失温（明确代价，禁止零代价碾压）。
  - 社会：旧秩序崩塌，幸存者聚成"暖巢""余烬会"等阵营，以热源与觉醒者为资源互相掠夺。
- **与现实的差异点**：存在"暖核"超凡力量与"霜蚀"低温异变；无丧尸病毒设定（与 AI 丧尸项目严格区分）。

### 4. 核心冲突
- **主角目标**：在永冬里活下去，并找回被"暖巢"带走的妹妹江熹。
- **最大障碍**：极寒环境 + 自身暖核反噬的两难；暖巢组织以妹妹为筹码要挟。
- **主要对抗关系**：江烬 / 暖巢（陆衡）理念与资源对立；江烬 / 自身反噬（能力代价）；人性善恶在物资匮乏下的拉扯。

#### 核心体系（异能等级 / 系统 / 游戏规则，逐条编号）
- **R1 暖核分级**：灰核（≤0℃微温）→ 赤核（常温）→ 焰核（灼）→ 曜核（熔）→ 曦核（未知上限）。每级对应温度阈值与能力上限，升级靠"吸热源"积累。
- **R2 觉醒条件**：极低温下濒临冻死 + 情绪峰值（求生/愤怒/护人）触发；并非人人可觉醒。
- **R3 反噬规则**：异能输出 > 暖核当前容量 → 施术者被自身寒蚀侵蚀，轻则冻伤、重则失温致死；禁止零代价释放大招。
- **R4 异能系别**：余温系（控热，江烬）、霜蚀系（控冰，邵凛）、及其他未明系别（留作长线扩展）。
- **R5 升级资源**：地热、明火、他人暖核"余烬"均可被吸收升温；掠夺他人暖核会触发反噬反伤（道德锚点）。
- **R6 霜蚀感染**：极寒 + 霜蚀结晶污染可使普通人半变异为"尸潮"，非病毒、可被余温净化（与丧尸设定划界）。
- **R7 人造暖核**：暖巢以活体觉醒者炼制，不稳定且反噬加倍——江烬拒绝使用，立价值观底线。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。
