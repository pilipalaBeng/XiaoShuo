# 《从零开始的男主路》人物档案（大男主 · 每集更新）

> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。
> ⚠️ **本书差异化契约**：核心爽点是"**升级与征服 + 世界观纵深**"，**打脸只是过程奖励**（宪法方向定稿句）；与赘婿"开局即巅峰"完全相反——**晏臣必须始终是从零往上爬**。

## 二、人物核心卡（静态人设 + 深化补充）

### 【晏臣】主角 · 观微觉醒者

| 字段 | 内容 |
|---|---|
| 身份 | 十六七岁，边陲小城底层少年；资质测为"平庸"（比下品还低，连边军杂役都不要）；观微之眼觉醒者；现裴歧门下的"看纹路"差役 |
| 核心欲望 | 表层：活下去、不回去砸石头（"他走了这么远，不是为了再回去砸石头的"）；深层：登临顶峰、护故乡（宪法） |
| 致命弱点 | ①资质平庸（启窍都勉强，须走险路频濒死）；②**观微折寿**（每次眩晕三息 + 一根白发）；③**心软**（宪法明列的判断失误根源，V4 埋点 ep11） |
| 性格标签 | 沉韧、记仇、护短；**"先看，再动"**——遇事先观察（蹲一下午看别人身上的纹、看监工肘弯卡壳的地方），看清了才出手 |
| 成长弧光（宪法） | 从"被刷下的平庸" → "世界屏障"；本档案细化为：→ ep01 被刷但看见裂痕 → ep02 第一次用观微（一枚石子破启窍监工）→ ep05-06 被宗门拒绝后被裴歧收徒（**从零开始**） |
| 口头禅/标志 | 攥拳、掌心留四道红印（从 ep01 掐到 ep05，一路没揉）；把白发收进兜里；"他不知道还能不能回去。"；身上干干净净（**无灵气微光**，是他最刺眼的标志） |
| 核心关系 | 阿绾（契约羁绊，共享感知）；裴歧（亦师亦敌，被利用）；晏母（故乡的情感锚）；战无咎（未登场的宿敌） |

**人设深化补充（宪法未写、正文已确立）**
- **"沉默"是他的防线**：看见裂痕不告诉任何人（ep01"他没有跟任何人说"）；被拒收不辩解（ep05 只问一句"为什么"就被"下一个"压回）；裴歧追问观微他不答。**他的成长是"从被动忍到主动算"的过程**。
- **"记仇"的具体化**：他把考官写"平庸"时"笔尖没有停一下"记在心里；他记下监工那种人会记仇，所以不敢再回采石场——**他的记仇不是情绪，是判断依据**。
- **护短是行动型的**：ep02 把水壶推给老工人，然后为一鞭子出手；ep03 明知危险仍引开异兽救陌生少女——**他的善意不喊口号，付的是自己的寿**。
- **"从零"的具体成本**：头发白了一根（ep02）、虎口裂口（ep03）、肩膀抓伤（ep04）、折寿（未明计数）——**写作时必须持续记账，不得让代价消失**。

### 【阿绾】女主级配角 · 化形异兽少女 ★本档案新增

| 字段 | 内容 |
|---|---|
| 身份 | 十五六岁模样少女；化形异兽，兽王后裔（V2，ep17 揭）；ep03 异兽夜袭时被晏臣所救；ep04 追上官道与其立契 |
| 核心欲望 | 跟她自己说的"顺路"（表层）；深层：弄清身世（宪法）+ 护晏臣 |
| 致命弱点 | **身份暴露会引兽王旧敌**（宪法）；立契后有虚耗；**影子不随呼吸动**（ep03 被人看破的破绽） |
| 性格标签 | 灵动、倔、重情；**说话不大但利**（"你傻站着干什么？"／"别用眼睛。"）；不放松（短刀一直在袖子里）；警惕性极高（ep05 蹲在墙根、眼神里有警惕） |
| 成长弧光（宪法） | 从躲藏 → 主动暴露护主；本档案细化为：→ ep03 一刀封喉救晏臣（但异兽绕她直扑晏臣）→ ep04 主动立契共享感知 → ep05 报警"后面有人" |
| 口头禅/标志 | "顺路。"；"别用眼睛。"；攥袖子里的短刀；耳动（"不是人那种动法"）；脚上破了口子的布鞋 |
| 核心关系 | 晏臣（契约羁绊，共享感知）；裴歧（警惕）；兽王旧敌（未登场的威胁，V8） |

**人设深化补充**
- **她的"帮"是付代价的**：ep04 立契后"脸色发白"、手很烫——**立契对她是消耗**；她抓晏臣手腕说"别用眼睛"，是因为她知道观微的代价。
- **她的功能是"信息优势 + 情感羁绊"的双重**：ep05 能摸脚印判断"跟丢了"、ep04 能听出"后面有人"——**她是晏臣在荒野/城市里的感知延伸**，但共享感知是双向的（"两个人的心跳混在一起，分不出哪个是他的，哪个是她的"）。
- **她的破绽已在 ep03 明写**：影子贴在墙上一动不动。**这是 V2 的第一块拼图，写作时必须保持"旁人偶然可见、当事人不点破"的处理**。

### 【裴歧】亦师亦敌 · 引路人

| 字段 | 内容 |
|---|---|
| 身份 | 中年，青衫，布鞋旧了但干净，步子"每一步都一样长，像量过"；引路人，收晏臣为徒但**不授功法** |
| 核心欲望 | 借晏臣完成自身布局（宪法）；"我等的，就是你这样的。" |
| 致命弱点 | 布局牵连旧债，不敢全信（宪法） |
| 性格标签 | 深沉、算计、护道；**声音很慢很淡，像两块石头落进深井**；不回答"怎么知道"，只回答"你不需要知道我怎么知道" |
| 成长弧光（宪法） | 从幕后 → 真容显露；本档案细化为：→ ep05 当街收徒（"别人看不出你。我看得出。"）→ ep06 自报名、点破观微、交"看遍全城纹路"的差事、立威 |
| 口头禅/标志 | "跟我走。"；"你不必知道我怎么知道。"；缺口的粗瓷茶碗（喝得很自然）；抬手一点画、威压立起 |
| 核心关系 | 晏臣（师徒亦利用，V3）；未知的"等的对象"（他为什么等这样的人？V3）；阿绾（扫过一眼，未点破） |

**人设深化补充**
- **他的"布局感"从第一面就写足**：店里的椅子"灰被擦过一块，他刚坐下不久"——**他不是路过，他是等在那里**。
- **他的教学法是"任务式"**：不授功法，只叫晏臣"从明天起，看遍这城里每一个人身上的纹路"——**目的不明，这是 V3 的核心悬念**。
- **他知道观微的秘密是最大谜**："你怎么知道？"——他不答。"别人看不出你。我看得出。"——**这句话既是收徒理由，也是最大的钩子**。

## 三、成长轨迹线（每个主要人物一行一锚点 · 只增不删）★本档案核心价值区

> 用途：这是本档案的**核心价值区**。宪法只写"开场→结局"两端，本区补中间过程。
> 更新规则：**每集追加一行，永不覆盖**；写新集前先读本区，确保人物没"跳变"。
> **本区覆盖 ep01–ep06 全部已写正文。**

### 晏臣

| 集数 | 变化锚点 |
|---|---|
| ep01 | **开局即最低点**：测灵石亮了一下就灭，考官划下"平庸"（比下品还低，连边军杂役都不要）；被刷后蹲在街角墙根吃干饼；**看见考官身上一道"将碎未碎的纹"（观微初醒，V1 埋）**；看了整整一下午别人身上的纹，"没有一个人提起，也没有一个人去看别人身上的纹"；**"他没有跟任何人说。"** |
| ep02 | 去采石场找活（唯一挣铜板的路）；**观微机制确立**：看清"纹走的地方就是灵气运行的地方，纹断的地方就是破绽"；监工抽打老工人时**用一枚鸡蛋大的石子精准砸在肘弯卡壳处**，监工灵气滞住、皮鞭脱手；**代价落地：眩晕三息、嘴里铁锈味、鬓边一根白发**（十六岁不该有的白发）；判断"这只眼每睁一次，都要从自己身上剜走一点东西"；"能换命。也能要命。" |
| ep03 | 异兽夜袭破城；**主动忍住不催动观微**（"今天折了一次寿。他不想再折第二次"）；用木棍从侧面引开异兽救下巷中被困少女；虎口裂开；**发现异常两点**：①异兽绕过少女直扑他 ②少女的影子"贴在墙上像画上去的"（V2 埋）；问出少女名字"阿绾"；"他不知道刚才救下来的，到底是人，还是别的什么。" |
| ep04 | 别母不告而别（只说"出去走走"），出城投中枢城（**小城已无他的路**）；官道半程阿绾跟上（"顺路。小城不安全了"）；山路遇红眼异兽扑袭，肩膀被抓伤；**阿绾喊"别用眼睛"，抓他手腕立契（R4 启用）**——共享感知生效（方位/心跳/紧张）；借方位感闪避，阿绾短刀杀兽；夜宿背风岩石后，**"他不再是一个人走这条路了"**；阿绾耳动示警"后面有人" |
| ep05 | 走七日（约）抵中枢城；**宗门报名处被拒**（执事写"不收。下一个。"，与 ep01 考官动作一模一样）；被华服少年拍肩"这儿不是你该来的地方"；**裴歧当街出现**："你。跟我走。"／"别人看不出你。我看得出。"（V3 埋）；他看阿绾一眼，阿绾警惕却点头；跟入无牌匾私门 |
| ep06 | **裴歧自报名、点破观微**（"你眼里有别人看不见的东西"）；问"你怎么知道"被"你不用知道我怎么知道"挡回；**裴歧展一手威压立威**（抬手间可把他按在椅子上）；**收徒但不授功法**，只交差事："从明天起，看遍这城里每一个人身上的纹路"；晏臣追问"你到底想从我身上要什么"，得到"**我等的，就是你这样的。**"（V3 推进）；**凭立契感应知阿绾在巷内守候**（"她在附近…他在警惕门外的动静"）；住进隔壁房间，"灯油耗尽，屋里彻底黑下来" |

### 阿绾

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从已写 6 集正文里提炼的"人物不可越过的线"。

1. **观微（R2）必有代价，禁止零成本**：每次使用=**眩晕三息 + 折损寿元（表现为一根白发）**。写作时必须"每次用、每次记账"，**禁止出现"随手一用"或"用了没反应"**。累计白发数应可在后续集数中被读者数出来。
2. **晏臣不喊口号、不解释、不自证**：他看见裂痕不说、被拒收只问一句"为什么"、被拍肩嘲讽不还嘴——**禁止让他讲热血宣言、心理长篇独白、或说"我一定会让你们后悔"**（那属于赘婿模板，本书差异化明令区隔）。
3. **打脸只是过程奖励，升级与征服才是核心**：ep02 石子破监工、ep09/19 越阶打脸——**每场打脸必须紧跟"境界/认知的实质推进"**，不得为爽而爽；**禁止连续多集只有打脸没有成长**。
4. **"从零"不可跳跃**：R1 境界九阶锁定。晏臣当前**仍在启窍**（ep06 状态库确认），**通络要等到 ep07 走险路濒死突破**。禁止提前给他任何高于启窍的实力量级。
5. **晏臣的"心软"是明写的致命弱点（宪法）**：V4 排期 ep11"制住敌首却放走"——**这是人物设定的一部分，不是败笔**；写作时必须让读者看见"他明知不该放还是放了"，且**付出故乡兽潮的代价**（ep13 回收）。
6. **阿绾不说话则已，说必简短带刺**："你傻站着干什么？"／"顺路。"／"别用眼睛。"——**禁止让她长篇抒情或撒娇**；她的情感靠动作（抓手腕、递干饼、耳动示警）表达。
7. **阿绾的身份信息真空**：V2 在 ep17 前**只给暗示不揭晓**（影子不随呼吸动、耳动非人、一刀封喉、异兽绕她直扑晏臣）——**禁止提前点破"她是兽王后裔"**，也禁止让旁人（含裴歧）说出真相。
8. **立契共享感知是双向的**："两个人的心跳混在一起，分不出哪个是他的，哪个是她的"（ep04）——**禁止写成单向感应或"心灵感应式作弊"**；她的紧张/虚耗应可被晏臣感知，反之亦然。
9. **裴歧不授功法、不解释动机**：他的台词必须"慢、淡、像石头落井"；**禁止让他长篇讲述身世/布局/图谋**（V3 排期 ep16/ep25/ep30）。
10. **裴歧的威压是"点到即止"的**：ep06 只写"不重，但够他知道"——**禁止写成碾压式威压或暴力威胁**；他的可怕在于"你能感觉到他如果想"。
11. **晏母不知情、不追来**：她只能作为**回忆里的声音/干饼/灶房动静**存在；**禁止让她忽然得知儿子下落或寻上门**（除非大纲排期）。
12. **敌兽战斗写战略不写碎尸（宪法 §3 平台红线）**：兽潮/异兽战斗**写走位、破绽、配合，不写血腥细节**；阿绾"一刀封喉"是干净利落的一刀，不是血溅描写。
13. **台词短句 ≤20 字、修行术语统一（宪法 §8）**：境界名（启窍/通络/凝液/化晶/御空…）、术语（观微之眼/折寿/越阶/灵气潮汐/异兽契约）必须与术语表一致，不得自创别名。
14. **战无咎（ep08 登场）/萧彻（ep12 登场）登场前不得填充细节**：只能按宪法定位存在，**禁止提前给外形、家世、功法、台词**。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字：晏臣/裴歧/战无咎/阿绾/萧彻）
4. **伏笔纪律**：本档案对 V1–V8 只记"人物侧"变化（谁知道了什么），**伏笔状态以《伏笔活表-大男主.md》为准，本档案不维护伏笔表**。
5. **代价账本（本书特殊要求）**：观微使用次数/白发数/折寿量应在本档案轨迹行中可持续累计——**这是本书"非无敌金手指"的监督机制**。
6. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定（尤其阿绾身份、裴歧图谋、晏臣弱点）。
