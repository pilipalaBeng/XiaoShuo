## 二、人物核心卡（静态人设 + 深化补充）

### 【江砚】主角 · 入赘三年被轻视的赘婿，实为苍穹隐退掌权者

| 字段 | 内容 |
|---|---|
| 身份 | 入赘岳家三年、被全家当废物的赘婿；真实身份=隐退的"苍穹"核心掌权者；三年前立誓"入赘三年不亮明身份" |
| 核心欲望 | 表层：护住妻子苏锦与岳家厂、清算舅兄吞产阴谋、了断宿敌楼枭；深层：**"拿回位置"与"不让身份伤到最该守护的人"之间的平衡** |
| 致命弱点 | ①承诺约束致前期被动（三年不暴露）；②**隐瞒伤妻**——因不能说，苏锦误会他出轨时他只能沉默（ep08 代价节点一）；③过度自信（ep26 低估总部反应被断资源，判断失误节点二） |
| 性格标签 | 沉稳、克制、护短；**藏锋型**——被羞辱不动声色、化解靠暗线；"眼神没离开过"（观察者） |
| 成长弧光 | 开场："忍辱藏锋"（被逼签净身协议仍压着旧部请辞信） → 中局：为护家破例动资源（ep09/ep14） → 结局（长线）："光明正大护家" |
| 口头禅/标志 | 摸旧铁牌（背面有划痕）；"信我一次。"（说出口却不能说清）；掌门令手机推送（挂着未回） |
| 核心关系 | 苏锦（情感锚，爱恨交织）；苏振海（家斗死对）；林岚（旧部/主仆亦友）；楼枭（宿敌）；王慧贞（岳母，被嫌弃）；苍穹总部（问责方） |

**人设深化补充（宪法未写、正文已确立）**
- **他的"金手指"是身份本身**：ep01 旧部请辞信落款"苍穹"+"要他回去归位"；ep02 林岚以秘书身份接头"信我看了""您打算压到什么时候"——**权柄靠旧部与权限体现，不靠异能**。
- **他的被动是性格也是誓言**：ep03 苏锦撞见神秘电话，江砚承诺卡在喉咙不能说——**"不能说"比"不想说"更痛，这是他最大的悲剧装置**。
- **隐退不止为护妻**：ep11 闪回三年前离城（车来接他走/苏锦站身后）、楼枭暗室"我等他三年"、苏家门口立誓——结尾"除了护她还有别的"留扣（V8）——**他心里还有一笔没清算的旧账**。

- **她的"留粥"是关系的体温计**：ep08 冷战但留粥——**表面疏远、内里不舍**，这是她"要强但重情"的具体写法。
- **她的成长落点在"补位"**：ep27 以厂长身份补上总部断掉的资源缺口——**家比身份重，她的价值不靠丈夫给**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。从已写 12 集正文里提炼的"人物不可越过的线"。

1. **江砚藏锋不软弱**：他被羞辱时不动声色（不是没脾气），化解永远靠"暗线+权限+观察"；不得写成逆来顺受或突然暴起打人。
2. **江砚的"不说"是誓言不是懦弱**：三年承诺（R1）是他自选的枷锁；写误会戏时他的痛苦来自"不能说"，不得写成为面子故意隐瞒。
3. **身份不得提前暴露**：V1 按 ep14（半露）/ep25 排期走；在此之前只能靠"旧部+权限+旧铁牌"给暗示，不得让江砚自揭或让人猜到全貌。
4. **旧部启用必须有正当理由**：护妻/护家/护厂才算（R3）；纯私欲动用会折损信誉——写江砚每次动资源都要能回答"为什么非做不可"。
5. **暴露代价是硬约束**：R2 从 ep13 起生效；提前动苍穹资源必惊动楼枭与总部，不得"用了没后果"。
6. **苏锦不是等待被救的花瓶**：她主动查、主动扛厂、主动留粥；她可以误会，但不可写成蠢；ep27 她要以厂长身份补缺口救场。
7. **苏振海智商在线不脸谱化**：他的算计循序渐进（意图→做局→话里藏刀），受挫后的反应是"查背后的人"而非暴怒失智；不得写成蠢反派（宪法定稿方向）。
8. **王慧贞的势利有护家底色**：她逼离婚是"为女儿体面"，不是纯恶；她的态度转变要靠"看见江砚护家"（ep19），不是被钱砸服。
9. **林岚的暴露=江砚的暴露**：写她时始终记着"她露怯会牵连旧主"；她的失误必须成为剧情压力（V5），不得只是搞笑桥段。
10. **楼枭是"看而不动"的猎手**：他的可怕在于耐心（"我等他三年"）；不得写成沉不住气、乱出手的莽夫。
11. **掌门令/总部是持续压力**：V7 不是一次性道具；每次出现都要提醒"归位 vs 护家"的两难（ep20/ep25-26/ep30）。
12. **护妻护家是全书道德落脚点**：所有打脸、反制、动用资源最终要落在"守护家人"上，不得写成纯炫富/纯权谋（宪法平台红线：反转要有道德落脚点）。
13. **对白短、腔调分明**：江砚克制话少、苏锦要强直白、苏振海话里藏刀、王慧贞刻薄带刺；不得所有人一个腔调（宪法节奏规则）。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
