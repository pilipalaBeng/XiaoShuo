## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《赘婿的隐藏身份》（工作书名）
- 题材 / 类型：赘婿逆袭（男频·身份反差向；差异化：隐藏大佬身份是引擎，开局即巅峰但被"三年不暴露"承诺锁住，护妻护家是情感锚）

- 验收尺子档位：A 短剧爽文档（节奏指标按 04-验收清单〇节该档替换）

### 2. 一句话卖点（Logline）
入赘岳家三年、被全家当废物的江砚，真实身份是隐退的"苍穹"核心掌权者；当三年不暴露的承诺倒计时归零，他一边守护妻子与摇摇欲坠的岳家厂，一边把吞产的舅兄与旧日宿敌一个个请下牌桌——但他的秘密，正在一点点伤到最该守护的人。

### 3. 世界观设定
- 时间 / 地点：当代都市江城，存在隐于幕后的商业/势力组织"苍穹"（非超自然，属财阀型权力网）。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 本书"金手指"是**身份本身**——江砚真实拥有的旧部网络与权限。
  - R1 三年之期：江砚立誓"入赘三年不亮明身份"，倒计时归零方可逐步归位。
  - R2 暴露代价：提前动用苍穹资源会惊动宿敌楼枭与总部，触发"巡察使问责"。
  - R3 旧部启用需"正当理由"（护妻/护家/护厂），纯私欲动用会折损信誉（江砚自我约束）。
- 与现实的差异点：顶级势力"苍穹"的存在被爽文化压缩，但权力逻辑（总部—掌权者—叛将）自洽。

### 4. 核心冲突
- 主角目标：护住妻子苏锦与岳家厂，清算舅兄吞产阴谋，了断宿敌楼枭。
- 最大障碍：三年不暴露承诺与"护家需动资源"的矛盾；宿敌楼枭借江城棋子反制。
- 主要对抗关系：江砚 vs 舅兄苏振海（家斗） vs 宿敌楼枭（江湖） vs 自我"隐瞒伤妻"的执念。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。
- **元叙事铁律（D 类 · 零容忍）**：正文（含叙述与人物对话）**绝不能出现 V1–V8 或 V9+ 任何伏笔编号、规则编号 R1–R3、决策门 D1–D3 等作者层面标记**。伏笔编号是作者台账，漏进正文 = 元叙事越界，本项目第一幕已犯 2 次（ep21 林岚说"V8"、ep30 叙述写"V1/V7"）。**每集写完 grep 必查：正文出现 `V\d` / `R\d` / `D[123]` 即打回重写，零容忍。**

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点（落脚于"护妻护家、光明正大"）。
- 平台规则变更时，以最新投稿规范为准。
