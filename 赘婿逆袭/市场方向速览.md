# 赘婿逆袭 · 市场方向速览（调研日 2026-09-22）

> 来源：番茄男频分析（战神赘婿为流量扛把子）。目标：个人创作，暂不上平台。

## 一、赛道判断

- 战神赘婿文是番茄"**流量扛把子**"：月榜前十男频至少三席，受众 30-45 岁男性，"忍辱负重→逆袭打脸"情绪宣泄刚需。
- 但**纯赘婿已内卷**：单纯退婚流热度暴跌，必须融合第二元素。
- 验收尺子：A 档（短剧爽文），爆款公式明确（见下）。

## 二、爆款公式（市场验证过的铁律）

1. 开篇 300 字内出现"三年之期已到"式的**反转预告**。
2. 主角**双重身份**：表面废物 + 隐藏大佬（战神/千亿富豪/神医）。
3. **每 3 章至少一次打脸**，爽点间隔短。
4. 兼顾家庭与事业：护妻/护家是情感锚，纯事业流不像赘婿文。

## 三、2026 创新方向（破内卷）

1. 融合流：赘婿+神医、赘婿+神豪、战神+鉴宝（《赘婿复仇，麒麟上身，我无敌了！》）。
2. **战神归来变体**：退伍军人/隐世高手回乡，解决邻里矛盾守护家人——贴近现实更易共情，比豪门赘婿接地气。
3. 女性向赘婿（妻主文）：女频换位版，与百合/大女主受众部分重叠。

## 四、开书建议

- 与重叠品类区隔：
  - vs 打脸虐渣：本书是**男频身份反差**主轴（隐藏身份是引擎）；打脸虐渣是女频复仇清算主轴。
  - vs 大男主：本书开局即巅峰（隐藏大佬），大男主是**从弱到强的成长体系**——两书战力结构完全相反。
- 避雷：无脑退婚流、反派全员蠢坏——2026 读者要求反派智商在线。
