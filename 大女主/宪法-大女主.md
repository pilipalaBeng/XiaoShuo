## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（工作书名）：《逆周期》
- 备选书名：①《资本不设性别》②《掌灯》③《她造的城》
- 题材 / 类型：大女主（无CP / 弱CP，单人事业主线）
- 预计总集数 / 单集字数：约 120 集 / 单集 1800–2500 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：20–40 岁女性，爱看事业逆袭、拒绝恋爱救赎
- 验收尺子档位：C 都市言情/情感流档（无CP——爽点全换"事业里程碑+决策高光"；节奏指标按 04-验收清单〇节该档替换）

### 2. 一句话卖点（Logline）
> 前世死在并购案里的金融分析师沈揭重生回 1998 年草莽股市，从一间快倒闭的营业部起步，靠信息差与规则漏洞做实业资本——不靠男人、不靠复仇，只靠每一次决策高光，把"女人做不了大事"的偏见碾成垫脚石。

### 3. 世界观设定
- 时间 / 地点：1998—2005 年，平行近史（沪深股市草莽期、国企改制、入世前后），非真实人物/事件影射。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 资本市场早期规则松弛但有红线：不许内幕交易、不许操纵股价（R3 边界）。
  - 信息差即利润：前世记忆提供"宏观周期 + 监管节点"的领先认知。
  - 实业为锚：纯金融空转不可持续，必须落回产业（R2 双轮）。
- 与现实的差异点：保留时代质感（BP机、营业部大户室、下岗潮余波），但所有机构、人名均为虚构，规避真实事件。

### 4. 核心冲突
- 主角目标：从零搭建一家以实业为底、资本为翼的本土投资机构。
- 最大障碍：时代对"女老板"的隐性歧视 + 监管周期的不确定性 + 对手盘的围剿。
- 主要对抗关系：沈揭 vs 对手方操盘手乔曼；沈揭 vs 体制惯性（以监管员林谕为代表）。

### 6. 核心体系（金手指 / 优势来源，逐条编号）

- **R1 重生记忆**：提供宏观周期与监管节点领先认知；代价——信息有时差、不可验证、用错一次即信用破产。
- **R2 实业+资本双轮**：只投能落回产业的项目，拒绝纯金融空转（防爽文式无代价碾压）。
- **R3 信息差变现边界**：红线——不内幕交易、不操纵股价；越线即触发监管反噬（林谕线）。
- **R4 人才识别**：主角核心优势不靠"系统"，而靠识人（周慎之、后期裴姓账房式人物），代价是用人必担责。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。

### 4. 本书特加红线（差异化契约）
- 标了无CP，就**绝不**偷偷塞恋爱救赎线；男性角色只当对手/下属/路人。
- 冲突来自事业对手与时代局限，不立"复仇"为唯一锚点（与打脸虐渣区隔）。
