# 《逆周期》人物档案（大女主 · 每集更新）

> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。
> ⚠️ **本书差异化契约**：标了无 CP，就**绝不**偷偷塞恋爱救赎线；男性角色只当对手/下属/路人。

## 二、人物核心卡（静态人设 + 深化补充）

### 【沈揭】主角 · 重生金融女

| 字段 | 内容 |
|---|---|
| 身份 | 重生者；前世国际投行并购副总裁（38 岁死在并购案）→ 现 23 岁营业部客户经理；沈家女儿，沈母之女 |
| 核心欲望 | 表层：做一家不被性别定义的资本机构（宪法）；深层：弄明白"我本不该出生"是什么意思（V7）、还清沈家那笔旧债（V1） |
| 致命弱点 | ①过度理性，早期低估人情与体制惯性（ep02 算对趋势算错人性、险穿仓）；②**"急"**——沈母点破"以前你急着赢，现在你急着查"；③为掩护重生身份，长期对最亲的人隐瞒（对沈母、对周慎之） |
| 性格标签 | 冷静、算计、护短；**决策型人格**——3 秒内看穿局面并动手；从不用情绪解决问题，用"账" |
| 成长弧光（宪法） | 重生归零 → 敢用感性补理性 → 立规矩者；本档案细化为：→ ep13 被沈母点醒"慢一点" → ep18 用别人的手艺替人洗冤（从算计走向成全） → ep29 立"三不铁律" |
| 口头禅/标志 | "要涨。但不是现在。"；"钱我来想。"；把证据折好塞进工牌后面/抽屉——**抽屉越来越厚 = 她的权力在长大**；从不看第二眼亏掉的数字 |
| 核心关系 | 周慎之（事业搭档，非 CP）；乔曼（镜像对手）；林谕（亦敌亦友）；沈母（情感锚/身世线索）；递笔人（前世真凶代理人） |

**人设深化补充（宪法未写、正文已确立）**
- **她的"快"是双刃剑**：ep02 满仓加透支险穿仓，是全书第一次"重生金手指失效"——**R1 的代价（信息有时差、不可验证）在这里第一次落地**：她知道终点价，但撑不到那天。
- **她学的是"算人性"**：ep02 周慎之的三行手算（下月利息/后天盯市/这礼拜工资）是她"从报表思维到产业思维"的转折点——她把那张纸塞在工牌后面，一直带着。
- **她从"贴账"到"晒账"的策略在进化**：ep19 主动把全链路明账贴在大户室墙上，**不是自证清白，是引蛇出洞**——"她怕的是对手不看。对手不看，就不知道她在等什么。"
- **她的护短是行动型**：ep18 为周慎之洗冤、ep14 用股权而非情绪留人——**她不说"我信任你"，她给股权、给订单、给清白**。

### 【周慎之】男主级配角 · 技术派合伙人 ★本档案新增

| 字段 | 内容 |
|---|---|
| 身份 | 江北机械厂技术员（干了十二年）；工装夹具专利被窃、被举报"泄密"背处分；后成为沈揭实业合伙（一成半股权） |
| 核心欲望 | 把手艺变成能落地的产业（宪法）；**深层：让"图是我画的"这件事被承认**（ep18 洗冤） |
| 致命弱点 | 不善交际、易被资本方轻视（宪法）；**背着"泄密"污名走了好几年**，眼白红是常年熬出来的 |
| 性格标签 | 木讷、靠谱、轴；**不算趋势，只算人性**（"你给工人发不出工资的那天，趋势再对，人也散了"）；嘴硬（"他干活的人，嘴硬。"） |
| 成长弧光（宪法） | 技术员 → 产业合伙人；本档案细化为：→ ep02 点破沈揭"算错人性" → ep05 亮出被窃专利草图、提自建军工厂 → ep18 军工厂首单洗冤（眼白里的红淡了一点） → ep21 支持逆周期收购印染厂 |
| 口头禅/标志 | "你急了。"；"趋势没错……你算错了人性。"；洗不掉的机油印、帆布包、两支笔插在胸前口袋；工作服上蹭手 |
| 核心关系 | 沈揭（事业搭档，非 CP，被"手艺"和"账"双重说服）；江北机械厂（出身/伤害来源）；军工厂技术员（认可者） |

**人设深化补充**
- **他是沈揭的"人性校正器"**：全书唯一能在专业上反驳沈揭的人，且反驳得对——**他的三行手算（下月利息/后天盯市/这礼拜工资）是 R2"实业为底"的第一次实物化**。
- **他的污名线是全书"账"的第三层**：朱四（僵尸书不适用）——本书中是"1989 画图 → 1992 被举报"，而举报他的是**沈揭前世的投行**（V4）——**他的冤案与她前世的签字直接挂钩**，这条线在 ep18 回收。
- **他的情感表达是技术的**：认可一个人的方式是"教他看机器"；对沈揭的信任体现在"他没问她钱从哪儿来，只问现金流撑不撑得住"。

- **他的"快"与沈揭的"快"是镜像**：她快在布局，他快在进度（"我比你早到半年"）；**两人都在同一张网上，只是动机不同**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从已写 22 集正文里提炼的"人物不可越过的线"。

1. **无 CP 契约（宪法 §4 本书特加红线）**：**绝不偷偷塞恋爱救赎线**；周慎之、林谕、赵总等男性角色只当搭档/对手/下属/路人，**禁止任何暧昧描写、禁止"他看她的眼神不一样了"式暗示**。
2. **沈揭的胜利必须靠"账"和"决策"，不靠男人救**：她每一次翻盘都是自己看穿局面（ep17 逼退赵总、ep19 晒账引蛇、ep20 交证据），**禁止让周慎之/林谕替她解决问题**。
3. **R1 有代价，不是无敌金手指**：重生记忆"有信息时差、不可验证、用错一次即信用破产"（宪法 §6）——ep02 险穿仓是范本。**禁止写"她全都知道所以她稳赢"**。
4. **R3 边界不可破**：不内幕交易、不操纵股价。她要赢，必须"用合规手段"——**这是全书最重要的规则红线**（ep29"三不铁律"是它的落脚点）。
5. **沈揭不解释、不辩解、不诉苦**：她被传"内幕女"时**不辩解**（"辩解没用。越辩解越像真的"），只做事。**禁止让她长篇自证或情绪崩溃**。
6. **她的"急"必须可见**：宪法弱点=过度理性；沈母点破的"急"是她的人物底色——**写她的行动必须有"赶"的节奏感**，但不得写成焦虑失控。
7. **周慎之只谈手艺和账，不谈感情**：他的话密时是在讲技术（ep18 讲二十分钟夹具）；**禁止让他表忠心、说漂亮话、示爱**。他认可人的方式是"教你看机器"。
8. **林谕不越权、不给透底**：他"能给你看的，只有这些"——**禁止让他一次交底全部旧案**；他的提问永远比回答多（"你怎么会这个签名"）。
9. **乔曼的帮必须有竞争性动机**：ep22"我砸你是想把你洗出去"是范本——**禁止把她的靠近写成善意施援**；ep25 挡刀的理由必须是"账要一起算"，不是情谊。
10. **沈母永不用说话解决秘密**：她的退场动作固定（刷锅/关灯/回里屋/关水龙头）；**禁止让她突然长篇倾诉或主动交代真相**（V7 排期 ep26）。
11. **赵总已退场**：不得复活；他的功能是"线"，其遗言"还有人在看你"可作威胁锚点引用，**不得滥用回忆**。
12. **马晓军已退场**：老鼠仓的尾巴（V3）已由他的七笔小单完成，**不得让他再出现或反过来做重要证人**。
13. **递笔人与林谕是两个人物**：**同名姓是刻意的混淆，不是伏笔**——写作时必须让读者能区分（一个查旧案、一个递东西）；ep28 前不得揭示递笔人身份/动机。
14. **沈父已故**：只能通过**旧账字迹 + 沈母转述**存在，不得闪回长场景或复活。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字：沈揭/周慎之/乔曼/林谕/马晓军/赵主任）
4. **伏笔纪律**：本档案对 V1–V8 只记"人物侧"变化（谁知道了什么），**伏笔状态以《伏笔活表-大女主.md》为准，本档案不维护伏笔表**。
5. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定（尤其身世、递笔人身份、乔曼的选择）。
