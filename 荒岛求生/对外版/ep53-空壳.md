# 第五十三章　空壳

苗青一早给林骁换外层布条，照旧先拿手背贴了贴他的额头。

烧还是那样，没退，也没再往上走。她拿省下的水蘸了旧布，擦了擦伤口外围，重新缠紧。手到最里头那层，停住。这伤能拖到今天，已经是她没料到的。她没多说，把那卷旧布叠好收在一边。

年轻水手今天送饭，撂下桶，顺嘴念叨了一句。

“前阵子你们那台相机。”他说，“戴帽哥拿去，叫人拆开看了看。里头啥也没有，卡早不在了。扔工具堆那边了，当废铁。”

他说得像在说一件不相干的事。说完，他把饼搁下，没看周屿。

周屿靠着货堆，没动。

他的手抬起来，摸了摸自己的手腕。腕上那道白印，是相机腕带缠了两年勒出来的，这会儿还在。相机拆了当废铁，这道印子还在他腕上。

那台机子他用了两年。哪颗钮按下去是录像，哪颗是拍照，他闭着眼都摸得出来。沉船前那一夜，他就着舱里的暗，拍下过底舱方向那团橙黄的火光。岛上试燃那天，他用掉最后一格电，按下快门，红灯亮一息就灭。后来卡装进木槽，捆好浅布，他亲手放进顺流里。再后来空壳叫戴帽收走，他解下腕带，叠两折压在身下。

现在连空壳也没了。壳叫人撬开，里头空的，扔在工具堆里，跟一堆扳手螺帽搁在一处。

他想起筏上那天。卡装进木槽，十字捆扎，竖枝系一条浅色布条，他站在齐膝水里，看布条变成一个小点。那个点顺流漂远，他不知道漂到哪儿，也不知道会不会有人看见。秦岸当时说，流有分支，得投主干。他们投了主干。剩下的，就不是他们能管的了。

他没说话。

苗青看了他一眼。周屿摇了摇头，意思是没事。

他不是没事。两年的东西，一夜之间漂走的漂走，拆的拆，扔的扔。可这会儿说这些没用。眼下他们四个都在这底舱里，说什么也变不回那台相机。

年轻水手走了以后，黑里，秦岸睁开眼。

舱里黑得什么都看不见。只有脚底下机器一直在震。

“都听见了。”他说。

周屿嗯了一声。

“相机卡。”秦岸说，“早跟那截木片漂走了。漂到哪儿，咱们不知道，也不能指望。空壳又叫人拆了扔了。这桩事，到这儿就算完了。”

周屿在黑里坐了一阵。

“完了也好。”他说，“省得惦记。”

秦岸没接这句。他知道周屿惦记的是什么。那台相机拍过沉船前的火光，拍过试燃的白光。卡漂走了，壳拆了，眼下连个能拿在手里的物件都没了。

秦岸自己也丢得精光。折叠刀叫搜走了，软丝断茬叫收走了，软尺、那点绳头，一样没剩下。苗青的量具、粘页笔记本、药草包，上船头几天就叫收了。周屿的相机、木片、拖饵线，一样没剩。连火种竹筒，都泡透了扔在脚边。四个人从岛上带出来的东西，到这会儿，全没了。

剩下的，就是四条命，一条没好利索的伤腿，和腿肚子上那一张纸。

他压声，把这几天拼到的东西，在黑里摆了一遍。

“舱号。”他说，“三号底舱，压水线。”

“航次。”他说，“这条线跑第五趟了，哪块浅哪块有巡的都熟。”

“货。”他说，“油布包底下那排无签金属罐，跟岛上贺连城那一箱同批。咱们看过。”

“船。”他说，“梯口上去是窄铁梯，到甲板。船那头有吊杆卸货。梯口上头有电话。”

他停了一下。

“这些，都在咱们脑子里。”他说，“没落在纸上，也没个物件能递出去。”

林骁躺着，一直听。这时候他开口。

“我腿上那张。”他说，“是不。”

“是。”秦岸说，“眼下就剩那一张。票根，舱位栏写着B舱，押运。缝在你绷带里，没人会碰。”

苗青压声接了一句。

“那张纸。”她说，“是咱们手上唯一的东西。别的，都没了。”

她说这话的时候，手还按在林骁腿上那个最里头的绷带上。她知道那张纸缝在哪儿，这些天换药，她的手一回都没碰过那个地方。

林骁嗯了一声。他动了动伤腿，让绷带不那么绷。那张纸就在他腿上，贴着他的血污，跟他一块儿躺着。

舱里静下来。机器在脚底震，铁板已经凉透了。底舱那股甜腥味，混着油布和铁锈，一夜散不去。

四个人心里都明白。这条船跑的是私线，舱里堆着同批的罐子。他们四个，是见过货的人。见过货的人，在长衫眼里是个麻烦。可麻烦怎么个了法，眼下谁也说不准。是靠了岸把他们扔在码头上，还是另有别的章程，长衫没说，船长没说，送饭的年轻水手也不知道。

秦岸靠在货堆上，闭着眼。他没说下一步。眼下没什么下一步可走。四个人被锁在三号底舱里，上头是甲板，甲板上有电话，电话那头是谁，他们够不着。

周屿还摸着腕上那道白印。过了好一阵，他才把手放下了。腕上那道印，往后还会在，可再也没有机子配它了。
