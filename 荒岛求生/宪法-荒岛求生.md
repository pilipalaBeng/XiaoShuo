## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：**《漂岛求生手记》**
- 3 个备选书名（有搜索区分度）：
  1. 《漂岛求生手记》（选定工作书名）
  2. 《海上安全屋：从一滴水开始》
  3. 《邮轮失事后，我靠知识活下来》
- 题材 / 类型：荒岛求生（近写实生存 + 物资流）
- 预计总集数 / 单集字数：约 90 集 / 单集 2000–2600 字（第一幕 ep01–ep30 已完成 71,353 字；第二幕 ep31–ep65 共 35 集，见《第二幕大纲-流上之船.md》；第三幕约 25–30 集待规划）
- 目标平台：个人创作（暂不上平台）
- 目标受众：男女通吃；求生知识向、写实生存、人性博弈受众
- 验收尺子档位：A 短剧爽文档（生存压力 + 能力成长双线；但**物资考据写实度高于一般爽文**，知识密度即爽点）

### 2. 一句话卖点（Logline）
> 邮轮沉没，户外求生教练秦岸和几个陌生人漂上无名岛；他没有金手指，只有一本早就刻进骨子里的生存知识——从第一滴冷凝水到扎出离岛木筏，每一步都靠真本事，也每一步都在和人性讨价还价。

### 2b. 一句话差异化（★明确写入，四书不得撞车）
> **荒岛求生 = 近写实生存 + 物资流**：无超凡力量体系（与末世异能划界），对手是自然本身；爽点来自"可学习的生存知识 + 物资里程碑可视进度 + 资源匮乏下的人性博弈"。

### 3. 世界观设定
- **时间 / 地点**：近当代架空公海，一艘观光邮轮失事后，幸存者漂流至一座无名热带孤岛（不对应任何真实国家/海域）。
- **核心规则（力量体系 / 社会规则 / 独特设定）**：
  - 近写实：无异能、无系统；全部解法须真实可行（取水、辨毒、结绳、搭棚、观星定位）。
  - 物资流：淡水/盐/火种为战略级，进度按"马斯洛式生存里程碑"明线推进。
  - 自然威胁：台风季、潮汐、暗流、毒物作为定时钩子。
  - 人性博弈：资源有限，分配冲突必有代价，禁止零成本和解。
- **与现实的差异点**：仅"无名岛存在旧观测站遗迹"作长线悬疑，其余遵循现实生存法则；无超自然。

### 4. 核心冲突
- **主角目标**：在岛上活下去，并带还活着的人发出求救、离开孤岛。
- **最大障碍**：自然（缺水缺盐、台风、毒物的不确定性）+ 同船者贺连城抢资源、制造分裂。
- **主要对抗关系**：秦岸 / 自然（生存主线）；秦岸 / 贺连城（资源与人性对立）；秦岸 / 自身独狼习性（前期不信任队友的误判）。

### 8. 节奏规则【参数区：取自 04-验收清单 A 档，叠加写实要求】
- 开场钩子：3 秒内冲突/打脸（沉船、缺水、被追三选一）。
- 爽点/钩子密度：每集 ≥2–3 个（知识解谜爽点 + 物资里程碑 + 人性反转）。
- 结尾要求：必须反转或悬念。
- 对白要求：短句 ≤20 字，动作推进优先。
- **写实硬指标**：每集至少 1 处"可学习"生存知识（取水/辨毒/结绳/搭棚/观星），考据细到可操作；禁止开挂式巧合。

#### 核心体系（生存知识 / 物资 / 游戏规则，逐条编号）
- **R1 生存马斯洛里程碑**：淡水 → 火种 → 庇护所 → 食物 → 医疗 → 离岛信号（明线进度，每达成一项即解压爽点）。
- **R2 物资分级**：战略级（淡水、盐、火种）/ 可循环级（工具、绳、容器）/ 紧缺级（食物、药材）；战略级短缺必引发冲突。
- **R3 知识考据规则**：每个生存解法须真实可行，禁止"恰好有宝箱/天降补给"式巧合；失误须按现实后果承担。
- **R4 海洋/天气规则**：台风季、潮汐、暗流为定时自然威胁，提供钩子与期限。
- **R5 人性博弈规则**：资源有限下分配冲突，决策必带代价，禁止零成本和解（立价值观底线：不美化掠夺）。
- **R6 信号规则**：卫星电话电量 / 信标次数受限，求救为长线悬念，不可轻易解决。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。
