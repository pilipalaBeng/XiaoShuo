## 一、为什么精修

前 24 集是流水线第一批产物，机械项全绿，但内容层有三类套式反复出现，读起来像同一个模板吐出来的：

1. **作者替读者总结心理**——人物还没反应，作者先替他把结论下了。
2. **段末金句收束**——每集结尾必有一句对仗式升华，把余味写死。
3. **同一句段内复读**——换个词把同一句话再说一遍，读者已经懂了，作者还在讲。

本轮新判定出第 4 类，也是批次里出现频率最高的：

4. **「没说出口 / 记在心里」同构套式**
   「他没把这句话说出口」「他把这一点，记在心里」「这件事，他也记下了」「这一课，他记着」。
   这四个句式在 ep03 / ep07 / ep08 / ep10 / ep13 / ep17 / ep20 / ep24 反复出现，功能是替人物盖章"此处应有触动"。
   盖一次是留白，盖七次就是作者在自己抄自己。

附带清掉的第 5 类：**作者代述推理**。典型是 ep20 原稿整段替读者推导"这电话不是用来叫救援的……秦岸不信"——推理过程本该让读者自己走完。

---

## 二、补偿手法（关键）

删掉这些句子，字数会掉。本轮**不靠加水回补**，一律用**同人设、同知识密度的具象细节**顶上：

- 删一句"他知道人心散了"，补一段"滤坑挪窝要连沙一起挖，坑壁那层湿沙不能散，散了水就浑"。
- 删一句"这一课他记着"，补一个动作"他把叶子重新盖回去，压上一块石头"。
- 删一段作者推理，补一段可验证的算式（浮力、盐量、时辰、步数）。

判据是 R3 写实：**读者能拿这段细节自己在脑子里做一次**，而不是被作者告知一个结论。

效果上看，24 集精修后字数不降反升（金句短、细节长），知识密度同步上升。

## 六、可复用判据（写作组 prompt 硬约束）

新写或改写任何一集，下笔前先过这五条：

1. 有没有替人物下心理结论？有 → 换成动作或物证。
2. 段末是不是在升华？是 → 删掉最后一句。
3. 同一句段里有没有换个词再说一遍？有 → 留一处。
4. 有没有出现「没说出口 / 记在心里 / 记下了 / 这一课」？有 → 换具体动作。
5. 有没有替读者把推理走完？有 → 只陈述可观察的事实，让读者自己推。
