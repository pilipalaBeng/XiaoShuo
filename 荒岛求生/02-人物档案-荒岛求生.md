> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。

## 二、人物核心卡（静态人设 + 深化补充）

### 【秦岸】主角 · 前户外装备测评员 / 野外求生教练

| 字段 | 内容 |
|---|---|
| 身份 | 前户外装备测评员、野外求生教练；少年时经历海难被陌生人救起，自此怕海却精通求生；与船上众人素不相识 |
| 核心欲望 | 表层：活下去，并带还活着的人发出求救、离开孤岛；深层：向当年救自己的人看齐——"从独自活到带人活" |
| 致命弱点 | ①独狼习性：不信任他人，前期因拒协作导致分队、险些害死人；②身体代价真实（脱水、伤口感染、熬夜眩晕）；③**水下僵直**（恐海，V3，遇深水即身体先于脑子僵住） |
| 性格标签 | 冷静、较真、嘴冷、护短（仅限肯信的人）；**先算规则再动手**的生存预判型思维 |
| 成长弧光 | 开场：只信自己、效率至上 → 中局：因误判吃瘪（ep09/ep17 代价），学会托付与协作 → 结局（长线）：从"独自活"到"带人活" |
| 口头禅/标志 | 先算代价再动手；"先活过今晚。"；用刀尖在沙上划线定规矩 |
| 核心关系 | 林骁（战力+医疗搭档）；苗青（知识后勤）；周屿（真相记录者）；贺连城（资源对立面） |

**人设深化补充（宪法未写、正文已确立）**
- **"假暖和"知识即人设**：ep01 落水后靠冷水失温常识自救（发木→犯困→脸发烫是危险前兆，掐掌心压住），知识流不是外挂而是他的骨血。
- **划线定规矩**：ep01 用刀尖划潮线教众人"别睡在浪够得着的地方"；ep10 定"退潮进、涨潮前出、洞口堆石系藤"——**规则感是他掌权的具体形态**。
- **误判的痛感写实**：ep09 把水放在贺连城够得着的地方（"刚救人一命，他不至于"），结果一夜丢光；他不当场发作，只跟林骁交换一个眼神——**隐忍型，用动作压情绪**。

| 性格标签 | 稳、重人命、寡言；行动先于言语（先蹲下捏开下巴看呛没呛水，再说话） |
| 成长弧光 | 沉默的医疗兵 → 秦岸最信的战力+医疗双支点 →（长线）成为团队"人命的锚" |

**人设深化补充**
- **医者本能高于自保**：ep09 台风夜把半口干椰汁让出去（"留着"），急救包护在怀里；ep10 探洞不先喝水、先记洞口方位。
- **与秦岸的无声默契**：ep09 秦岸发现水丢后"只跟林骁交换了一个眼神"，林骁也明白了——**两人之间不需要解释，这是全书最早的信任样本**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。从已写 10 集正文里提炼的"人物不可越过的线"。

1. **秦岸不圣母也不恶毒**：救人必先算代价；底线是"不对普通人见死不救"，但绝不为救人送死（ep09 教训后更明确）。
2. **秦岸永远是"先算规则再动手"**：任何危机先找可操作的写实解法（取水/辨毒/结绳/观星），不靠武力、不靠运气、不靠"恰好有宝箱"（R3）。
3. **秦岸的恐海是身体反应不是心理独白**：写 V3 只写僵住、抬不起胳膊、气卡胸口，不得长篇抒情或提前闪回当年海难（ep22 才回收）。
4. **知识不等于零风险**：秦岸的每个解法都须真实可行且可能失败；失败后按现实后果承担（脱水/感染/眩晕），无金手指豁免。
5. **林骁是行动先于言语的**：他先做（检查、包扎、让水）再说话；不得写成话痨或情绪外露型。
6. **苗青不神化自己懂的东西**：她永远说"认得/不敢打包票"的边界话，不得写成万事通或自信满满地断言药效。
7. **周屿的相机是稀缺资源**：电量告急是硬约束；每次开机都要有叙事重量，不得随意"随时有电"。
8. **贺连城是"利己但不傻"**：他每一步算计都自洽（先护箱、藏电话、偷水挪箱），不写成脸谱化蠢反派；被打脸时是"学乖不敢顶"，不是暴怒失智。
9. **前人暗线信息真空**：ep18 前只给痕迹（脚印/血点/采摘痕/刻字），不得闪回、不得让人物说出来、不得提前填动机。
10. **贺连城不得提前下线**：按大纲 ep26 揭沉船真相、ep30 被留岛上；在此之前只能作为持续的"资源对立+疑点"存在。
11. **秦岸与林骁/苗青/周屿之间不写恋爱线**：本书为群像生存流，情感以"托付与信任"呈现（宪法未立 CP，勿擅自加）。
12. **台风季/潮汐是定时器不是背景**：R4 的自然威胁必须真实提供期限与钩子（ep09 台风兑现、ep15 洋流仅 2 小时），不得写成随叫随到的便利设定。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
