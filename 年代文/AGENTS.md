## 三、核心规则速记

- **每集流水线**：读基准 → 定素材 → 写正文 → 跑验收 → 独立审核 → 更新状态库 + 伏笔活表 + 进度清单 → git commit → 交付
- **独立审核**：六项硬检查；打回 ≤3 轮；重大偏离停止并上报
- **决策门**：D1 每集确认；D2 剧情重大调整先登记宪法《修订记录》再更新再续写；D3 发布动作必须用户手动
- **设定合法性**：正文出现的每条新设定须能在宪法找到依据或登记新增，凭空发明 = 打回
- **人物连续性（强制）**：写前读《02-人物档案》轨迹+关系+红线，防跳变/OOC；写后追加上集锚点（只增不删）
- **长篇防漂移**：宪法管不变、状态库管变、伏笔活表管实况（唯一源）、审核每集拦截；每幕末跑全书大审计
- **写作契约（强制）**：任何写作任务开工前先读《小说写作通用规则.md》；标点 A 类机械必检，交付前跑完 §八自查清单
- **外部技能边界**：只做补强不托管流程；产出须过验收 + 审核；与项目文件冲突时以项目文件为准
