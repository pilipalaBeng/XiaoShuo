## 二、人物核心卡（静态人设 + 深化补充）

### 【宋棉】主角 · 重生女

| 字段 | 内容 |
|---|---|
| 身份 | 19 岁（身体），前世破产个体户的心智；梧桐镇宋家姑娘；重生回 1984 年 |
| 核心欲望 | 表层：带全家脱贫、让宋家酱站住脚；深层：把前世"被自家人坑垮"的坑提前填掉，替娘把没说完的话做完 |
| 致命弱点 | **心软、不敢谈钱**（V8，ep14 显形、ep18 收）；对"自家人"的信任有历史包袱；前期无本金、无执照 |
| 性格标签 | 勤快、算得清、护家；**记账型思维**——先算账再开口；克制，不砸招牌不撕破脸（"砸招牌最泄愤，也最掉价"） |
| 成长弧光 | 怕得罪人、见堂姑只会站着发抖 → 立家规护全家 → 用账本自证清白 → 从摊到铺、从镇到县城 |
| 口头禅/标志 | "账上写着呢。"；"一步一步来。"；随身小本记账、账本上写小字 |
| 核心关系 | 奶奶（从"不被信"到"被托方子"）；宋铁（护与被护）；宋菱（学费承诺）；堂姑（死对头）；老吴（事业引路人） |

**人设深化补充（宪法未写、正文已确立）**
- **不是"未卜先知"，是"多摔过一回"**：ep23 明确她克制使用 R1——她判价差会收窄，凭的是前世做过生意的经验，不是预知政策。写她"料事如神"时必须落到"经验"而非"神通"。
- **算账是她的情感语言**：她安慰人、护人、表态，都用账本。ep07 劝奶奶放权说的是"万一哪天您身子不舒服，这账不就断了"；ep07 按住哥哥的手说的是"手是咱家最大的本钱"。
- **不动手开关**：面对堂姑，她三次克制——ep16 不去砸招牌、ep19 不去对质、ep21 识破眼线也不声张，靠"酱对味"让市场投票。
- **她的软处在娘**：ep19 见到酱方末页半行"棉丫头要是……"，她"没哭"，把方子贴胸口收好——所有情绪用动作压住，是她一贯的隐忍方式。

### 【宋老太太（奶奶）】女主级配角 · 持家权威

| 字段 | 内容 |
|---|---|
| 身份 | 宋家当家老太太，爷爷辈的持家权威；旧式，不识字但有"见好就收"的世故 |
| 核心欲望 | 家不能散；孙女（宋棉）能立住，宋家有个正经营生 |
| 致命弱点 | 保守、重面子（"家丑不可外扬"、"账哪能这么写出来"）；算账只在自己心里算，不肯摊开 |
| 性格标签 | 嘴硬心软、嘴上不饶人、背地疼人；说话带"死不了"式的硬壳 |
| 成长弧光 | 不放权、只信自己心里那本账 → 头回把家底摊在纸上（ep07）→ 把守了十几年的真方交孙女（ep19）→ 拍板"去县城但根留这"（ep28 计划） |
| 口头禅/标志 | "死不了。"；"别好高骛远。"；"反正你心里有数就行。"；旧银簪、黑围裙、手帕包里的棺材本 |
| 核心关系 | 宋棉（从质疑到托付）；宋铁（长孙，最疼）；宋菱（"那丫头成绩好，是个指望"）；堂姑（表面客气、内里防备） |

**人设深化补充**
- **"硬话—软动作"结构**：ep16 她嘴上嫌宋棉"又不是相亲，换这么齐整做啥"，转身翻出干净帕子塞她手里"擦擦手再拿。那纸金贵"。这是她全部的爱的方式，写她必须成对写。
- **放权的三个台阶**：ep07 添账（把米缸粮票写进白纸）→ ep13 第一次放权教全家做酱讲"你娘若在，该高兴"→ ep19 交出真方（"它跟了你，比在我这老婆子手里，活泛"）。轨迹不可跳级。
- **不识字但懂人**：她看不懂涨跌，但她懂"见好就收，比贪到底强"，是宋棉商业判断之外的另一种智慧。

|---|---|

| 核心欲望 | 进厂站稳、转成正式工（工资从 18 块涨到 32 块）；护住妹妹的摊子 |

| 成长弧光 | 学徒（手伤险废前途）→ 养伤期用左手干活护摊 → 手伤养好、进厂体检通过（ep22）→ 待转正为骨干 |
| 口头禅/标志 | "棉子！"；"我这身板，百八十斤不在话下。"；"这手是妹子挣来的。"；护掌手套（ep17 起）、骑二八大杠、铝饭盒 |

**人设深化补充**
- **他的"轴"是行动力的另一种形态**：ep05 见赵歪嘴欺负妹妹，"也不废话，上去就推"——不权衡、不计代价，与宋棉的"先算账"形成兄妹性格镜像。
- **手是叙事道具**：ep05 手伤埋 V3 → ep17 戴特制手套干活 → ep19 戴手套不敢碰娘的酱方（"不敢碰那纸，只在边上探头"）→ ep22 手养好、体检过。手的状态就是他的命运刻度。
- **闷声的好**：ep05 厂里发几颗糖都省下来给妹妹，ep05 一句"今儿的事，别跟奶奶说。她夜里睡不着"。

| 成长弧光 | 上门索方（ep01）→ 抢先报名/假祖传（ep06）→ 造谣反被自证逼退（ep14-15）→ 执照被撤、假方败露（ep16/ep19）→ 靠山在县城（ep30 幕末钩子） |

**人设深化补充**
- **不是脸谱恶人，是"让人怜爱"的恶**（宪法红线）：ep16 她被撤照后"脸上的笑，僵了一下"却仍嘴硬；ep19 甚至托县城远房亲戚想兑方子找落脚处——**有落魄、有狼狈**，不搞血腥报复。
- **她的败因在"方子本身"而非对质**：ep19 老吴捎话，县城老师傅一看就乐"祖传的方子，哪有撕了半页的"——她"脸挂不住，夹着方子走了"。败露得自然，没人去戳穿。
- **她的威胁是真的**：ep16"县城里，还有人"，是实话不是狠话。第二幕（县城商战）她是引线。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从 ep01–ep23 正文里提炼的"人物不可越过的线"。

1. **宋棉的"料事如神"必须落在经验上，不落在神通上**：她判价差收窄凭"做过生意知道"，写她"预知政策/未卜先知"即 OOC（ep23 明确否定了"未卜先知"）。
2. **宋棉不砸招牌、不撕破脸**：面对堂姑三次克制（ep16 不砸招牌、ep19 不对质、ep21 不声张），她的胜利靠"酱对味"和市场投票，不靠暴力或对骂。
3. **宋棉的"心软"是有代价设定的**：赊账、帮人必有边界（家规"救急不救穷"），心软要用"代价"兑现，不能免费发善心。
4. **宋棉的所有情感表达都走"算账/动作"**：她不哭不闹，情绪用记账、攥手、收方子等动作压住（ep19"没哭"是常态，不是例外）。
5. **奶奶必须"硬话—软动作"成对写**：嘴上嫌、背地疼；只写硬话会变刻薄，只写软动作会失真。
6. **奶奶放权不可跳级**：ep07 添账 → ep13 放权做酱 → ep19 交真方，三级台阶逐级递进，不能一步到位。
7. **宋铁的"轴"是行动力，不是愚笨**：他是个实诚能干的学徒，任何危机"什么都不想就上"要在兄妹/家庭的语境下，不能写成拖后腿的糊涂人。
8. **宋铁的手是命运刻度**：手伤状态必须与 V3 进度一致（ep05 伤 → ep17 手套 → ep22 养好体检过），禁止提前"手已痊愈"。
9. **堂姑是"让人怜爱"的恶，不是脸谱**：她有落魄、有狼狈（ep19 夹方子走人），禁止写成血腥报复对象；她的威胁"县城还有人"是真实话。
