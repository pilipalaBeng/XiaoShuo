## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（工作书名）：《供销社那年的糖》
- 备选书名：①《1984年我带全家致富》②《票证年代的小买卖》③《回春巷》
- 题材 / 类型：年代文（重生 + 家长里短 + 烟火气逆袭）
- 预计总集数 / 单集字数：约 120 集 / 单集 1800–2400 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：25–55 岁女性，宝妈与中年读者，爱烟火治愈与搞钱双情绪
- 验收尺子档位：C 都市言情/情感流档（叠加搞钱爽点；节奏指标按 04-验收清单〇节该档替换）

### 2. 一句话卖点（Logline）
> 重生回 1984 年梧桐镇的宋棉，带着前世下岗破产的教训，从一坛祖传酱菜、一台补衣机起家，用一手好手艺把濒临散伙的大家庭拧成一股绳，带全家从缺粮少钱逆袭成镇上头一份个体户——靠的是人情账，不是金手指碾压。

### 3. 世界观设定
- 时间 / 地点：1984 年（平行近史），江南小镇梧桐镇；个体户刚合法化、粮票布票仍部分流通、供销社为主渠道、价格双轨并存。所有机构人名虚构，不影射真实事件。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 票证经济：粮票/布票是硬通货，会算票才能盘活资源（R1 机遇节点）。
  - 个体户名额稀缺：镇上只批有限执照，争夺即冲突源（R3 账本共治）。
  - 供销社渠道垄断：想走量须经营老何式人情（R4 杠杆）。
- 与现实的差异点：保留时代质感（的确良、二八大杠、供销社开门喊、市管员），但政策仅作背景氛围，不正面描写敏感政治事件。

### 4. 核心冲突
- 主角目标：带全家脱贫并保住亲情，不做前世"被亲戚坑垮"的孤注。
- 最大障碍：家底薄 + 极品亲戚（堂姑）不断挖坑 + 自己"不敢谈钱"的心软。
- 主要对抗关系：宋棉（全家）vs 堂姑一房；宋棉 vs 自身性格代价。

### 6. 核心体系（金手指 / 优势来源，逐条编号）

- **R1 重生记忆**：提供时代机遇节点（个体户政策、双轨价差、特产外销）；代价——只给认知不给本金，用错一次即失信。
- **R2 手艺变现**：酱菜/缝纫/小吃，靠手上功夫落地，非系统碾压。
- **R3 全家经营账本**：家庭共治、民主算账，防"一人独断翻车"，也绑定亲情。
- **R4 供销社人脉杠杆**：老何线可走量，但须还人情、守规矩（不缺斤少两）。

### 9. 节奏规则【参数区：从 04-验收清单所选档抄过来，写作时遵守】

- 开场：3 秒内情绪冲突或烟火气切入点（一声喊、一桩事）。

- 结尾：情绪悬念或事业留白；亲情向，不写雌竞。
- 对白：自然口语，方言味克制（少量"丫头""俺"点缀），允许长句。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点。

### 4. 本书特加红线（差异化契约）
- 烟火气是生命线：粮票/供销社/的确良等时代细节须准确，但**不正面描写敏感政治事件**。
- 女主清醒不蠢；恶亲人设"让人怜爱"而非真恶，不搞血腥报复（与打脸虐渣区隔）。
- 重家庭经营与治愈，不立恋爱为主线（与大女主区隔在"单人事业登顶"，本书重全家）。
