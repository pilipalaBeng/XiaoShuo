> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局两端），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。
> 当前进度：已写 ep01–ep22；下一集 ep23-24（证据链闭环二/老金察觉清理；城东黑幕上热搜、股价闪崩）。

## 二、人物核心卡（静态人设 + 深化补充）

### 【顾屿】主角 · 归来清算者

| 字段 | 内容 |
|---|---|
| 身份 | 曾被合伙人背刺、恋人倒戈、全网唾骂、净身出户的前创业者；三年后带"清算清单"归来；正本投资实控人 |
| 核心欲望 | 表层：逐条清算背叛联盟、恢复清白；深层：**回答"我回来是为了讨公道，还是为了把输掉的那口气连本带利赢回来"**——证明自己"赢得起也收得住" |
| 致命弱点 | **过度掌控欲**，为抢节奏会把人当工具用（ep14 误伤梁志远）；手上"想赢的手开始往脏的那边伸"（ep15 钟宛点破） |
| 性格标签 | 冷峻、算计、外冷内执；**"说话永远留三步"的应对方式**；看细节（先看陆竟袖口） |
| 成长弧光 | "以牙还牙"的复仇者 → 误伤无辜后自我怀疑 → 主动低头道歉（ep17）→ 守 R2 留体面出口（ep18）→ 狠而有度 |
| 口头禅/标志 | "我回来，是要查一笔旧账。"；短句、冷峻；清算清单（白纸逐条写名字）、牛皮纸信封 |
| 核心关系 | 陆竟（死敌）；钟宛（互证互救的盟友，有裂痕）；沈以棠（爱恨交织）；老周（亦父亦友）；老程（引路人，"你得比他们干净"）；老金（当前最大对手） |

**人设深化补充（宪法未写、正文已确立）**
- **他的道德罗盘来自老程那句话**："你得比他们干净。学了，你就输了。"ep10 与 ep15 两次靠这句话刹车——这是他"狠而有度"的施行机制，写他"收手"必须落到这句。
- **"自我怀疑"是他的转折机制**：ep15 钟宛问"你难受，是因为觉得做错了，还是怕这事败露坏了你的局"，他"答不上来"；ep15 他独坐一夜"没想着怎么赢，在想怎么才能不变成自己最恨的那种人"。**他的成长都发生在独处时的自审里**。
- **他的自律表现是"主动收手"**：ep10 发三行字护陆竟家人、ep18 不追陆竟个人家底——两次都是他主动放掉的筹码，是他区别于陆竟的证据。
- **他记念人情的方式是物件**：ep01 盯着陆竟袖口那枚"我们俩凑钱买的"袖扣；ep18 收到"算你狠"短信不回。

### 【陆竟】前期反派 · 前合伙人

| 字段 | 内容 |
|---|---|
| 身份 | 顾屿前合伙人，虚增成本吞并公司；明面反派；身后受城东资本控制 |
| 核心欲望 | 保住吞下的资产与体面；把顾屿再赶出去一次 |
| 致命弱点 | **护妹心切**（妹妹是被拿捏的软肋）；贪婪但留有把柄在别人手里；靠城东信用撑着 |
| 性格标签 | 圆滑、贪婪、护短；"语气像在谈天气"；说话永远留三步（先摆价码，再请警察） |
| 成长弧光 | 台前嚣张（ep01 当众清场）→ 反扑（ep08 买水军）→ 被立案（ep09）→ 资金链崩、被城东弃子（ep18）→ "算你狠"未认输 |
| 口头禅/标志 | "你回来，是想分一杯羹。"；"我给过你台阶，你不下。"；袖扣（ep01 未换的旧物证） |
| 核心关系 | 顾屿（死敌）；老金/城东资本（控制方，已弃他）；妹妹（软肋） |

**人设深化补充**
- **"留三步"是他人格标签**：ep01 先口头给两百万再请经侦进门——**他每一步都预设退路，也因此每一步都可被证据链拆解**。
- **他的崩法是"掉体面"不是"掉命"**：ep18 舆论让他"当年花大价钱买下来的那点体面，一块一块，掉在了地上"；顾屿守 R2 留他活路，为他"狗急跳墙或反咬"留了伏笔。
- **他是"弃子"，不是终局对手**：ep18 城东"连他电话都不接"。第二幕真正的对手是老金/城东资本。

| 成长弧光 | 追踪者（ep02 接线索）→ 与顾屿并肩（ep08-ep13）→ **裂痕爆发（ep15 独立行动）** → 补全关键证人（ep16）→ 关系缓和（ep18 配合公开清算） |
| 口头禅/标志 | "我以为你不一样。"；"你得想清楚了再答。"；拍打印件在桌上 |

**人设深化补充**
- **她是全书的道德标尺**：ep15 那句"你正在变成陆竟那样的人"、"你再这么下去，连你自己都不认识"是顾屿性格转折的唯一驱动力——**顾屿的成长是被她骂醒的**。
- **她的"独立"不是散伙**：ep15 明说"不是单干，是我得按我的方式来"，她与顾屿共用一个目标，只是拒绝"把人当棋子"。裂痕是"没散，是裂了"。
- **她的技能点是"抠一行字"**：ep10 从"急病去世"的邮件里抠出社保提前一个月转走的破绽，推出会计还活着（V4）——**她的调查靠细节不靠人脉**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从 ep01–ep18 正文里提炼的"人物不可越过的线"。

1. **顾屿可以狠，但必须"收得住"**：每次清算都要落到 R1（公开证据链闭环）/R2（留体面出口）的边线上，写他"赶尽杀绝、逼人至死"即 OOC。
2. **顾屿的"收手"必须有内心依据**：他的刹车来自"老程那句别学他们"与自审（ep15 独坐一夜），不能凭一时心软或情节方便。
3. **顾屿的成长都发生在"独处自审"里**：不写他不经过思考就突然高尚；他的每次转身都要有一夜/一次对话的铺垫。
4. **顾屿不靠武力、不靠运气**：他靠证据链+资本+舆论三件套，任何危机先找"证据/合规/舆论"的路径，禁止动手。
5. **顾屿必须为"狠"付出明确代价**：误伤（ep14）、盟友裂痕（ep15）、低头道歉（ep17）、后续监管函（ep27 计划）——**代价链条不可省略**。
6. **陆竟不降智**：他会反扑（ep08 水军）、会留退路（ep01 留三步）、会求生（ep18 卖公司），**任何"反派突然犯低级错误"都是 OOC**。
7. **陆竟的崩法是"掉体面"不是"掉命"**：写他落魄、被弃，但不得写血腥/暴力收场；R2 给所有人留合规退路。
8. **钟宛不是顾屿的下属**：她有独立判断与行动线（ep15 独立、ep16 独自找证人），写她"听话配合"即 OOC；裂痕是真实存在的。
9. **沈以棠保持"未真倒戈"的模糊态**：ep22 之前不得坐实她的立场，她的一切行为都受"母亲是人质"约束。
10. **老金"不依套路"**：他的高明在于看穿主角旧招（ep10 叫停水军）——写他只会砸钱买水军、降智送人头即 OOC。
11. **老周、老郑等供应商的"没留底"是隐喻底色**：他们的伤痛是"没证据"的历史代价，不可写成单纯卖惨工具。
12. **梁志远是把柄持有者，不是纯受害者**：和解不等于清零——"旧日把柄仍压两人之间"必须保持张力（V6 未消化）。
13. **对白短句 ≤20 字、冷峻利落，全员不同腔调**：顾屿短冷、陆竟圆滑、钟宛锐利、老周市井、老金沉稳——禁止所有角色同一张嘴。
14. **主角的资本操作必须合规**（R3）：走对赌/并购/股权，不碰洗钱与违法；越线埋监管伏笔（ep27 兑现）。
15. **无超自然力量**：本书"金手指"是现实向的"清算账本机制"，禁止出现异能/系统/超能力。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 人物卡 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
5. **人名以《术语表-打脸虐渣》为准**：顾屿（非顾宇/谷屿）、陆竟（非陆竞/陆敬）、钟宛（非钟婉/钟苑）、沈以棠（非沈忆棠）、老周（非老邹）、老金（非金总）、老程（非程先生）、老郑（非老郑头）、老魏（非魏哥）、梁志远（非梁总监）、老何（非何会计）。
