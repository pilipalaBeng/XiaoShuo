## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《清算清单》（工作书名）
- 题材 / 类型：打脸虐渣（男频·复仇清算向；差异化：靠证据链与资本布局逐条清算，非超能力碾压）
- 预计总集数 / 单集字数：约 300 集 / 单集 1500-2200 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：男频 22-40 岁，偏好"清醒硬刚、利己有度、以智复仇"的读者
- 验收尺子档位：A 短剧爽文档（节奏指标按 04-验收清单〇节该档替换）

### 2. 一句话卖点（Logline）
曾被合伙人背刺、恋人倒戈、全网唾骂净身出户的顾屿，三年后带着一份逐条清算的"复仇账本"归来，用完整证据链与资本布局，把昔日践踏他的人一个个请下神坛——但他必须先学会：清算可以狠，却不能滥。

### 3. 世界观设定
- 时间 / 地点：近未来都市（约 2026 年），以江城商界为舞台，无超自然力量。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - 本书"金手指"是**现实向**的——一套完整的"清算账本"机制：证据链 + 资本 + 舆论三件套。
  - R1 每清算一人，必须公开"证据链闭环"，否则主角声誉反噬。
  - R2 舆论反杀须给对方留"体面出口"，逼人至绝路会触发监管与法律反噬（主角自身也受此约束）。
  - R3 资本布局须合规（走对赌/并购/股权，不碰洗钱与违法），越线则埋监管伏笔。
- 与现实的差异点：信息战与资本战被高度"爽文化"压缩到集级别推进，但逻辑闭环仍自洽。

### 4. 核心冲突
- 主角目标：逐条清算当年背叛联盟，找回清白与尊严，守护暗中相助的盟友。
- 最大障碍：对方掌握旧日舆论定调权 + 幕后金主"城东资本"的势力网。
- 主要对抗关系：顾屿 vs 前合伙人陆竟（明面） vs 城东资本（暗面） vs 自我"以牙还牙"的执念。

### 8. 节奏规则【参数区：从 04-验收清单所选档抄过来，写作时遵守】

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不美化犯罪；反转要有道德落脚点（本书落脚于"狠而有度、清白自证"）。
- 平台规则变更时，以最新投稿规范为准。

4. **每集写完后**：向《02-人物档案-打脸虐渣.md》追加本集成长轨迹锚点（只增不删）+ 更新关系网。
