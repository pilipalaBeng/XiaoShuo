## 三、核心规则速记

- **每集流水线**：读基准（宪法/状态库/进度/伏笔活表/本幕大纲）→ 定素材 → 写正文（2000-3000 字）→ 跑验收清单 → 独立审核 → 更新状态库 + 伏笔活表 + 进度清单 → 交付
- **独立审核**：按《审核Agent职责》六项硬检查；打回修改 ≤3 轮；重大偏离（改结局/改人设/改世界观/新增核心规则）停止并上报
- **决策门**：D1 每集确认；D2 剧情重大调整先登记宪法《修订记录》再更新再续写；D3 发布动作必须用户手动
- **规则合法性**：正文出现的每条规则须能在宪法规则库找到依据或登记新增，凭空发明 = 打回
- **长篇防漂移**：宪法管不变、状态库管变、伏笔活表管伏笔实况（唯一源）、审核每集拦截；宪法改动必须留痕；每幕末跑全书大审计——细则见 07-工作流总纲 §八
- **外部技能边界**：`zmxxcb-ai-master`（去AI味）仅局部调用（文风诊断/清洗/发布前检查），默认不主动调用；产出须过项目验收 + 审核，**文风基准优先于该技能的通用规则**（如破折号/引号用法冲突时以《文风基准》为准），不碰剧情与设定——细则见 07-工作流总纲 §七
