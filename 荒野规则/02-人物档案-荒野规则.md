# 《荒野规则》人物档案（每集更新）

> 用途：这是 AI 续写时的"人物连续性记忆"——宪法 §5 人物卡管"静态人设"（开场→结局），
> 本文件管"人物怎么走到结局的"（过程/轨迹/关系变化），补齐"宪法管两端、状态库管本集"之间的断层。
> 与动态状态库分工：**状态库管"本集快照"（位置/持有物/当前目标，每集覆盖）；本档案管"历史轨迹"（只增不删，永不覆盖）**。
> 更新人：AI 在每集完成后追加（不做覆盖式改写）。
> 更新规则：**每集完成后必更新**；新人物登场先建卡；人物发生性格转折/关系质变时追加"轨迹"行，不修改历史行。

## 二、人物核心卡（静态人设 + 深化补充）

### 【陈默】主角 · 看见者

| 字段 | 内容 |
|---|---|
| 身份 | 26 岁，前户外生存博主；灾变中在枯树区醒来；面板持有者（能看见规则篡改痕迹） |
| 核心欲望 | 表层：活下去、找到失踪的妹妹；深层（ep19 后）：替老鬼走完没走完的路、弄清"为什么选我" |
| 致命弱点 | 体力普通；前期面板功能不全；**过度理性、习惯独自扛事**（不肯轻易托付，ep15 后才学会结盟） |
| 性格标签 | 谨慎、观察入微、不圣母但护短、嘴贫（冷幽默）；**规则预判型思维**——先算代价再动手 |
| 成长弧光 | 从"只想保命的独行者"→"敢对抗规则本身"→"敢把人放进自己计划里"（结盟小乙）→"主动承担看见者的历史责任" |
| 口头禅/标志 | "我没事。"（硬撑时的固定句，ep42 第五遍）；先算规则再动 |
| 核心关系 | 妹妹（情感锚/同行者）；小乙（结盟搭档）；小七（互坑互救）；王建国（敬重的前辈/灰度镜子）；老鬼（精神接力） |

**人设深化补充（宪法未写、正文已确立）**
- **算账型善良**：帮人必先明算账（ep16 帮小乙断图腾=换看全档案纸），不是无私，是有底线的交易型善意。
- **不动手开关**：面对规则从不硬闯，永远先找"规则的缝隙"（ep21 用规则预判绕废弃车、ep42 走斜线躲石头）。
- **隐忍的痛**：妹妹失踪是他唯一的失态开关；找到妹妹前，所有情绪都用动作压住（攥拳、停一瞬、把话说短）。

- **冷静到近乎理性**：见到六年未见的哥哥，第一反应是判断而非情绪（"他太会说了，你进去是看他不是听他"）。
- **记号习惯**：走到哪刻到哪（墙上箭头、铁碗底小花），是她的生存方式也是留给哥哥的路标。

## 三、成长轨迹线（每个主要人物一行一锚点 · 只增不删）

> 用途：这是本档案的**核心价值区**。宪法只写"开场→结局"两端，本区补中间过程。
> 更新规则：**每集追加一行，永不覆盖**；写新集前先读本区，确保人物没"跳变"。

### 陈默

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。这是从 42 集正文里提炼的"人物不可越过的线"。

1. **陈默不圣母也不恶毒**：帮人必明算账；底线是"不对普通人见死不救"，但绝不为救人送死（王建国的"别在把油烧光"是他的行为准则）。
2. **陈默不硬闯规则**：任何危机先找规则缝隙，不靠武力/运气解决。
3. **妹妹不是等待被救的弱角色**：她有独立判断和行动力；对书写者保持警惕（"他太会说"）。
4. **小乙的情绪是外露的**（对比陈默的隐忍）：他会怕、会急、会说"你别信我"，但关键时刻最决绝。
5. **小七毒舌但不轻浮**：它说规则时用【】，吐槽归吐槽，涉及"书写者"关键词仍会熔断（协议约束未解除）。
6. **王建国已退场**：不得复活、不得以回忆滥用（仅可作情感锚点，ep19 后引用需克制）。
7. **老鬼已除名**：仅可作残稿/前史引用。
8. **记录者信息真空**：ep47-48 前不得填充身份/动机，只能给暗示。
9. **城已停转**：登记员/秩序科转后方，不作为主战场反派频繁出场（第二幕大纲 §五·6）。
10. **面板=限制器而非外挂**：陈默的等级/功能始终有代价，不给"无限升级碾压"。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
