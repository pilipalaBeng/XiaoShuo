# 短剧小说创作宪法（模板）

> 用法：每开一部新剧，复制本文件改名（如 `宪法-战神逆袭.md`），填完第一部分「故事圣经」后交给 AI 全程遵守；第二部分「写作规则」为固定守则，所有剧通用，不用改。
>
> 原则：**约束一致性，不束缚发挥**。规则只锁两件事——故事世界不跑偏、红线不触碰。

### 8. 节奏规则（短剧硬指标，AI 写作时必须遵守）
- 每集开场 3 秒内必须出现钩子（冲突、悬念或异常）。
- 每集至少 2-3 个爽点（打脸、反转、金手指兑现）。
- 每集结尾必须留悬念或反转，逼观众点下一集。
- 对白短句为主，单句不超过 20 字；场景转换要快，单场景不超过全集的 1/3。

## 第二部分：AI 写作规则（固定守则，所有剧通用）

### 1. 风格基调
- 语言风格（网文感 / 剧本感 / 半剧本半小说）：
- 叙事人称（第三人称 / 第一人称）：
- 对白风格（口语化 / 犀利 / 含蓄）：

### 2. 禁用清单（去 AI 味自查项）
- 删："不仅仅是 X，更是 Y" 式排比三连。
- 删：空洞金句结尾（"那一刻，命运开始转动"）。
- 删：破折号泛滥、感叹号堆砌（！！！！）。
- 删：万能形容词堆叠（"璀璨的、神秘的、无与伦比的"）。
- 改：每段不超过 3 行，动作推进优先于心理描写。
- 对白必须符合人物身份，禁止全员说同一种腔调。

### 3. 格式规范
- 剧本格式：`场景标题（内/外景·地点·日/夜）` → 动作描述 → 人物名+对白。
- 分集文件命名：`第XX集-集名.md`，一集一个文件。
- 每集开头附：本集大纲、涉及人物、伏笔标注。

### 4. 平台红线（投稿前必查）
- 自查敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
- 价值观：不得美化犯罪、宣扬拜金/复仇过界；反转要有道德落脚点。
- 平台规则变更时，以最新投稿规范为准。

### 5. 审核流程（AI 每写完一集自动执行）
1. 节奏：开场钩子达标？爽点数量达标？结尾悬念达标？
2. 逻辑：人物动机是否成立？时间线是否冲突？
3. 一致性：对照人物卡与伏笔总表，有无吃设定？
4. 红线：敏感词扫描通过？
5. 输出结论：达标 / 需修改（列出问题点）。

---

## 使用说明（怎么让 AI 遵守）
1. 开新剧：把填好的本文件 + 集数进度，一起发给 AI（可以直接发文件链接）。
2. 每次续写前，先让 AI 读一遍本文件再动笔。
3. 剧情有重大调整（改结局、改人设）时，先更新本文件再继续写，避免漂移。
4. 本模板为通用版；写顺手后可按个人习惯增删条目，但"人物卡 + 伏笔表 + 节奏规则 + 红线"四项建议保留。
