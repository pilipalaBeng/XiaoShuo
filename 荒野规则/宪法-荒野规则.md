## 第一部分：故事圣经

### 1. 项目信息
- 剧名：**荒野规则**（已定）
- 题材：科幻末世 · 荒野求生 · 规则怪谈 · 系统面板
- 总集数规划：长篇，首批先跑 3 集验证，看反馈再扩
- 单集篇幅：网文版 2000-3000 字/章（短剧改编为远期选项）
- 目标平台：待定（独立小说；网文连载为主，发布前再定）
- 目标受众：男频，18-35 岁，喜欢生存流+解谜+爽文打脸的读者

### 2. 一句话卖点（Logline）
文明崩塌后的荒野里，每片区域都有必须遵守的"生存规则"，违反即死；普通社畜陈默觉醒了能看见"规则篡改痕迹"的面板，在别人靠运气活、靠死人验证规则时，他知道——**规则里有一条，是写给死人看的。**

### 3. 世界观设定
- **时间/地点**：近未来，一场被称为"大静默"的灾变后第 47 天，城市废墟与荒野交界带。
- **核心规则（世界规则）**：
  1. 灾变后，荒野中出现一个个"规则场"（区域），每个区域有数条白纸黑字般浮现在意识中的生存规则。
  2. 违反规则者会"被除名"——当场异变/消失，化为怪物的一部分。
  3. 规则之间存在矛盾与暗改，不是所有规则都可信。
  4. 幸存人类聚集在"中继站"（规则完全正确的安全点），中继站之外是荒野。
- **与现实的差异点**：规则可视化为文字、违反即死；荒野中存在"知道规则但说不出来"的旧世界 AI 残骸。

### 4. 核心冲突
- **主角目标**：活下去，并找出"谁在篡改规则"。
- **最大障碍**：规则被暗中篡改；改写规则的存在（暂称"书写者"）就在幸存者之中或附近。
- **主要对抗关系**：陈默 vs 利用规则吃人的幸存者骗子（老鬼类）；陈默 vs 隐藏的书写者（暗线）。

### 6. 核心爽点公式
- 每集至少一个"规则反转"：读者以为规则A保命，主角发现A是坏的，反手用规则B反杀。
- 面板升级：解锁新功能（规则可视化、篡改标红、区域预警）。
- 打脸固定句式：骗子说"听我的"→ 主角引用规则条文 → 对方违规，当场被除名。

### 7. 前 3 集分集大纲

**第 1 集《醒来，就是第一条规则》**
- 开场钩子（3 秒）：荒野废墟，变异怪物啃食尸体，陈默在血污中睁眼，脑中冰冷浮现文字【生存规则·枯树区】。
- 规则三条：①听到身后三声呼唤，不要应答，不要回头；②天黑前进入标着绿色叉号的山洞；③洞外积水不可饮，除非结冰。
- 核心事件：旁边另一个幸存者听到呼唤、回头、应声——当场异变。陈默压住恐惧，按规则摸向山洞。
- 结尾反转：跑进山洞，就着绿光看清岩壁，绿色叉号下方一行小字：**"本规则已被篡改。"**
- 新埋伏笔：V1（规则篡改）；V4（岩壁第三道刻痕特写，不解释）
- 回收伏笔：无（开篇）

**第 2 集《洞洞里的 AI 》**
- 开场钩子：山洞深处传来电子音——【第 7 号终端已激活】，一架破损军用无人机亮起红灯。
- 核心事件：小七启动，警告"这山洞不安全，别碰第三道刻痕"；洞口被一队幸存者堵住，为首者（老鬼）谎称"规则是离开山洞的人不许回头，你躲在洞里就该被除名"，要逼陈默出来送死抢物资。
- 爽点：陈默反用规则——他指出"背对洞口说话的人，三句之内不能说出洞外的事"（他刚在岩壁上读到的第四条），让老鬼背身喊话，对方一句谎刚出口就触发规则异动，全队被迫退走。
- 结尾反转：小七说出半句——"书写者……他就……"红灯狂闪，自毁保护启动，断线："距离下次可沟通，72 小时。"
- 新埋伏笔：V2（小七来历）；V5（老鬼会回来）
- 回收伏笔：V4（第三道刻痕，本集揭晓为"不可触碰"）

**第 3 集《中继站的灯》**
- 开场钩子：面板升级【生存者等级 1】，新任务弹出：前往中继站，全程 8 公里，限时入夜前。
- 核心事件：途中遇到一支幸存者小队（含护士苏晓），队里老人——老鬼——换了个身份，用"善意"劝新人交出物资："跟着我，我知道正确的规则。"
- 爽点：陈默当众指出老鬼给出的"规则"与面板显示不符（篡改痕迹标红），老鬼恼羞成怒亲自示范"规则正确"，迈出违规一步，被荒野除名——尸体消失前只留下一句："中继站……早就不是安全的地方了。"
- 结尾反转：远处山脊，中继站的轮廓亮起，广播在所有人耳机里响起："欢迎来到规则之城。这里的规则，全部正确。"——全部正确，反而意味着更可怕。
- 新埋伏笔：V6（苏晓的手环有旧文明科技痕迹）；V7（"规则之城"四字）
- 回收伏笔：V5（老鬼回归并被自己的规则吞噬）

### 8. 规则样例（枯树区，写作素材库）
1. 听到身后三声呼唤，不要应答，不要回头。
2. 天黑前必须进入绿色叉号标记的山洞；洞内不可触碰第三道刻痕。
3. 洞外积水不可饮用，除非它结冰。
4. 背向洞口说话的人，三句之内不得说出洞外之事。
5. （被篡改版）"绿色叉号的山洞永远安全。"／（真实版）"安全屋只在灯亮着时安全。"
6. 不要相信任何自称"规则执行者"的人。

## 第二部分：写作规则（本剧专用）

### 1. 风格基调
- 语言风格：紧凑、画面感强、短句为主；生存感+悬疑感，偶有冷幽默（主要靠小七的毒舌）。
- 叙事人称：第三人称限知视角（只写陈默知道的，读者和主角同步解谜）。
- 对白风格：口语、短、带钩子；规则条文用【】标出。

### 2. 写作铁律（通用契约 + 本剧强化）
> 完整 A/B/C/D/E 五类铁律 → 见 **《D:\Project\模板库\小说工作流模板\小说写作通用规则-模板.md》**（所有书公共契约）。以下为本剧必须额外守住的硬约束。

**通用铁律摘要（违者打回）**
- **标点（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式（B 类）**：禁"不仅仅是 X，更是 Y"式三连、空洞金句收尾、感悟拔高。
- **词汇（C 类）**：禁万能形容词堆叠；同段禁高频复读同修饰词。

**本剧强化（《荒野规则》专属）**
- 改：动作推进优先；规则条文必须短、怪、可验证；不写大段心理独白，用动作体现。
- 规则条文一律用【】标出，格式短促、反常理、可当场验证。
- 冷幽默只许走小七的毒舌，不让旁白抖机灵。

### 3. 格式规范
- 每集一个文件：`ep01-醒来就是第一条规则.md`。
- 每集开头附：本集规则清单、涉及人物、新埋伏笔编号。

### 4. 红线自查
- 不美化犯罪；主角"不圣母"但有底线，不可对普通人见死不救到恶毒。
- 恐怖画面点到为止，不写血腥细节。
- 规则杀人的逻辑自洽优先于猎奇。

### 5. 每集完成后五步审核
1. 节奏：开场 3 秒钩子？规则反转/爽点≥1 个？结尾悬念？
2. 逻辑：规则条文前后矛盾吗？
3. 一致性：对照人物卡（静态）+《02-人物档案》成长轨迹/写作红线（动态）与伏笔表，有无吃设定、有无 OOC？
4. 红线：血腥/价值观自查？
5. 输出：达标 / 需修改（列问题点）。
