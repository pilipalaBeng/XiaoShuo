## 一、节奏检查（必过）

| 项 | 要求 | 结果 |
|---|---|---|
| 开场钩子 | 3 秒内出现冲突/悬念/异常（第 1 句话不能是环境描写） | ☐ |
| 规则反转/爽点 | ≥1 个（读者以为 A 安全 → 发现 A 坏 → 反手用 B 打脸） | ☐ |
| 结尾悬念 | 最后一句是钩子（反转、异常、疑问） | ☐ |
| 场景切换 | 快切，单场景不超过全集的 1/3 | ☐ |
| 对白 | 短句为主，单句 ≤20 字，符合人物身份 | ☐ |

## 二、逻辑检查（必过）

| 项 | 要求 | 结果 |
|---|---|---|
| 规则条文 | 前后矛盾？规则是否自洽（怪但可解释）？ | ☐ |
| 人物动机 | 每个行动都有动机支撑？ | ☐ |
| 时间线 | 与状态库时间线冲突？ | ☐ |

## 三、一致性检查（必过，对照宪法+状态库）

| 项 | 要求 | 结果 |
|---|---|---|
| 人物卡 | 行为/对白符合人物卡？无 OOC？ | ☐ |
| 伏笔表 | 本集新埋伏笔已登记？应回收的已回收？ | ☐ |
| 设定 | 世界观/金手指能力边界无吃设定？ | ☐ |
| 状态库 | 本集后的状态（位置/物资/人物状态）已同步？ | ☐ |

## 四、红线检查（必过）

| 项 | 要求 | 结果 |
|---|---|---|
| 血腥 | 恐怖画面点到为止，无血腥细节 | ☐ |
| 价值观 | 不美化犯罪；主角"不圣母"但有底线 | ☐ |
| 敏感词 | 无暴力/色情/违法/影射真实人物 | ☐ |

## 五、文风检查（建议项）

| 项 | 要求 | 结果 |
|---|---|---|
| 去 AI 味 | 无排比三连/空洞金句/感叹号堆砌 | ☐ |
| 画面感 | 动作推进优先，无大段心理独白 | ☐ |
| 台词 | 无全员同腔调 | ☐ |

## 每集验收后必做（更新顺序）

1. 更新 `01-动态状态库.md`（人物状态/地点/伏笔进度/最近3集摘要）
2. 更新 `00-进度清单.md`（该集状态、字数、伏笔）
3. **验收存档（固定机制）**：把本清单"验收结论"以上内容复制为一份新文件存入 `验收存档/epNN-验收.md`，然后把本清单的"验收结论"区清空待用（检查项模板不动）。禁止直接覆盖旧记录、禁止口头存档。
