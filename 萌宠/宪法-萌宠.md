# 《萌宠》宪法

> 用法：每开一部新书复制本文件改名（如 `宪法-书名.md`），填完第一部分后交 AI 全程遵守；第二部分为固定守则。
> 原则：约束一致性，不束缚发挥。规则只锁两件事——故事世界不跑偏、红线不触碰。
> 修订纪律：任何设定改动，先登记文末《修订记录》再改正文；只改不删。

## 第一部分：故事圣经（每书填一次）

### 1. 项目信息【参数区】
- 书名（暂定）：《末世兽语》（工作书名）
- 题材 / 类型：末世+萌宠·动物视角/异兽团宠流
- 预计总集数 / 单集字数：约 280 集 / 单集 2000–2800 字
- 目标平台：个人创作（暂不上平台）
- 目标受众：女性向为主，末世/治愈/轻喜剧/非对称依赖关系爱好者
- 验收尺子档位：**C 都市言情/情感流档**（情绪价值主供给：治愈暖点+轻喜剧+虐点，节奏指标按 04-验收清单〇节 C 档执行）

### 2. 一句话卖点（Logline）
天灾末世里，能听懂兽语的少女带着一只毒舌灵猫逃难，路上一只只异兽主动认她当"妈妈"，她没想当救世主，却成了末世里最被团宠的那个人——而代价，是她自己正一点点"变成"它们。

### 3. 世界观设定
- 时间 / 地点：近未来架空，一场"大雾"天灾降临后的第三年；人类退守"避难基地"，野外被雾蚀区与原生/异变动物占据。
- 核心规则（力量体系 / 社会规则 / 独特设定）：
  - **动物视角/异兽团宠**为本书核心：主角能听懂兽语，异兽以"投喂+信任"认主（非武力收服），团宠关系是非对称依赖（人给家、兽给陪伴与战力）。
  - 天灾以"大雾/雾蚀"呈现，**非病毒非丧尸**；人类吸入雾蚀会"失语失忆静止"，不写成尸变嗜血。
  - 动物可进化出灵智（异兽），部分能说话；异兽凝聚"灵核"作能量。
- 与现实的差异点：兽语互通、动物进化开智、雾蚀致感官异变；无科幻机甲，偏轻奇幻末世。

### 4. 核心冲突
- 主角目标：带活墨爷与团宠们活到雾散，找回失踪弟弟林小野。
- 最大障碍：自身"动物化"加深的代价；猎兽会捕兽取核；基地高层欲控"兽语者"。
- 主要对抗关系：林小满（护宠寻弟）↔ 猎兽会/基地高层（夺兽语者与灵核）↔ 雾蚀自然威胁。

## 第二部分：AI 写作规则（固定守则，所有书通用）

### 0. 第一原则（最高优先级）
**自然优先。** 任何规则让文字变僵硬、变机械、变得"一眼 AI"时，规则让位于自然表达。（细则见《小说写作通用规则.md》§0）

### 1. 写作铁律（违者直接打回 · 完整条款见《小说写作通用规则.md》）
> ⚑ 本宪法只留最硬的三条"牙齿"；完整 A/B/C/D/E 五类铁律 + 每集自查清单，全部收在本书目录内的《**小说写作通用规则.md**》。**写任何一集之前，先读通用规则。**

- **标点铁律（A 类）**：对话引号必须成对且为标准 `"…"`，**严禁 `""` 连排/引号错配**；破折号每集 ≤ 2 处；感叹号每集 ≤ 3 处且不连排。机械必检，必须清零。
- **句式铁律（B 类）**：禁"不仅仅是 X，更是 Y"式三连排比；禁空洞金句收尾、感悟拔高；禁"不是……而是……"滥用。
- **词汇铁律（C 类）**：禁万能形容词堆叠（璀璨/神秘/无与伦比……）；同段禁高频复读同修饰词。

> 完整 A1-A8 / B1-B6 / C / D / E 条款 → 见《小说写作通用规则.md》§一～§五。
> **交付前强制自查**：对照通用规则 §八"每集自查清单"逐项打勾，A 类机械扫描零违规方可送审。

### 2. 格式规范
- 正文文件命名：`epNN-集名.md`，一集一个文件。
- 每集开头附：本集规则/涉及人物/伏笔标注（便于审核对照）。

### 3. 平台红线（投稿前必查）
- 敏感词：暴力血腥、性暗示、赌博、违法情节、真实人物影射。
