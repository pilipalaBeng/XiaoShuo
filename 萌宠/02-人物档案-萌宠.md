## 二、人物核心卡（静态人设 + 深化补充）

### 【林小满】主角 · 19岁兽语者

| 字段 | 内容 |
|---|---|
| 身份 | 19岁，末世前宠物店帮工，天生兽语者；大雾降临第三年带着黑猫墨爷逃难 |
| 核心欲望 | 表层：活下去、护住团宠、找回失踪的弟弟林小野；深层（ep12 后）：**弄清母亲那代兽语者的命运，回答"我该不该被需要"** |
| 致命弱点 | ①心软常因收留陷险；②体能弱（凡人之躯）；③**动物化失控风险**（灵核共享致指尖生绒毛、感官异变，V5）；④对墨爷的来历一无所知（信任建立在信息不对称上） |
| 性格标签 | 温柔倔强、护短；**用"被需要"定义自己**；不擅长拒绝任何求她的动物 |
| 成长弧光 | 开场：被动逃难（只想活命） → 中局：主动团宠领袖（认主、策反灵兽、救人） → 结局（长线）：从"动物妈妈"到能选择边界的兽语者（ep30"下一程，你得自己选边"） |
| 口头禅/标志 | 对动物蹲下来平视；"我听得见。"；背包里弟弟的旧绳结与引人北上的旧鳞 |
| 核心关系 | 墨爷（搭档/嘴替）；团子（"妈妈"关系）；祁寒（人类线支柱）；林小野（寻弟主线）；林若兰（身世谜） |

**人设深化补充（宪法未写、正文已确立）**
- **兽语是"听懂"不是"命令"**：ep01 首觉醒时只能听懂、还不会说服（R2 被动为主）；ep11 才第一次用兽语"策反"被俘灵兽——**能力有成长曲线，不是一步到位**。
- **她的"妈妈"身份是被动的**：ep07 喂流浪狗群被齐声喊"妈"、ep08 团子开口叫"妈妈"——**她没想当救世主，是动物们主动认的**（宪法核心设定落地）。
- **代价写在她自己身上**：ep06 为救团子共享灵核、指尖长绒毛（V5）；ep14 感官兽化加深、险被体检令查出——**团宠的暖与她自己的"变成它们"同步推进**。

### 【墨爷】核心搭档 · 黑猫异兽

| 字段 | 内容 |
|---|---|
| 身份 | 黑猫异兽；毒舌护主、第一搭档；真实身份=前代兽王之子，化猫守人界（V3，ep24 回收）；旧称"小玄"（ep04 守门人叫出） |
| 核心欲望 | 表层：守好"这具身子认的主"（林小满）；深层：**隐瞒身份、独自扛下与猎兽会的旧账** |
| 致命弱点 | ①真身暴露会被猎兽会围捕；②**傲娇误事**（有话不说、独自赴险）；③被叫旧称受刺激（ep04 当场炸毛喝止） |
| 性格标签 | 毒舌、嘴硬心软、傲娇；**用嫌弃表达关心**；关键处决绝（ep10 不再逃、龇牙迎战） |
| 成长弧光 | 开场：独行猫（隐瞒身世） → 中局：从"逃叛兽"到"迎战"（ep10）、独自赴险（ep15） → 结局（长线）：愿为人界留下的秘密守护 |
| 口头禅/标志 | 尾巴甩脸；毒舌吐槽；"这具身子当年也是人"（ep03 失言又否认） |
| 核心关系 | 林小满（认的主）；团子（同伴）；祁寒（互认实力）；猎兽会（旧主/旧账，曾是他们的人）；母亲林若兰（旧约，ep24） |

**人设深化补充**
- **身份靠"马脚"一层层漏**：ep03 那一跃、那声吼、失言"这具身子当年也是人"；ep04 守门人叫旧名"小玄"它炸毛；ep10 被猎人认出"叛兽"它亲口承认"早先是他们的"——**V3 用四次递进埋而不揭**。
- **它的"独自赴险"是性格缺陷也是深情**：ep15 夜探猎兽会老巢、只留一句"若我不回，别找"——**它宁可小满恨它，也不愿她涉险**，与它"嘴硬心软"人设完全自洽。
- **一句"别找"的分量**：这是全书第一个"角色主动切离"的节点，也是小满第二幕成长的引爆点。

| 字段 | 内容 |

| 成长弧光 | 开场：懵懂毛球 → ep08 开智开口 → ep16 透支假死 → ep18 灵核反哺复苏、进化成侦察眼 → 结局：小队侦察眼 |

- **它是"弟弟线"的导航仪**：ep08 嗅到北方"会疼的小的"指向弟弟；ep18 定位到弟弟信号在猎兽会运输队——**萌宠有独立功能（V6 侦察眼）**。

## 五、人物写作红线（防 OOC）

> 用途：写每集前扫一眼，防止人物走形（OOC）。从已写正文里提炼的"人物不可越过的线"。

1. **兽语是"听懂"为主不是"命令"**：小满能听凡兽情绪/预警，可有限说服异兽；不得写成"想指挥谁就指挥谁"的控兽外挂（R2）。
2. **动物化是硬代价、只增不减节点**：指尖绒毛（ep06）、感官异变（ep14）都是有去无回的推进；不得让代价"自己好了"，也不得让她一步变兽（V5 排期 ep20 才到临界点）。
3. **团宠靠"投喂+信任"不靠武力**：认主必须是被动式（动物主动来），不得写成武力收服或签契约（R4）。
4. **墨爷不写成单纯毒舌宠物**：它说每句狠话都在隐瞒（身世/旧账）；涉及"小玄""叛兽""当年"这类词必须触发它的反应（炸毛/回避/喝止），不得轻飘飘带过。
5. **墨爷真身在 ep24 前不得揭晓**：只给马脚（旧名/那声吼/犬臣服/叛兽称呼），不得让人物说出"你是前代兽王之子"。
6. **团子不得成人化也不得沦为纯搞笑挂件**：它的语言是幼儿逻辑（叫"妈妈"、碎碎念），但每次出场要推进"弟弟线/侦察"功能，不做纯笑点（宪法：萌宠有独立功能）。
7. **祁寒不说破组织内幕的时间点**：ep17 才透露高层与猎兽会勾连；此前他只能"帮场""带路"，不得提前揭基地黑幕。
8. **妈妈（林若兰）信息真空**：ep25 前只给"照片+被逐记录+末页被撕"；不得闪回母亲本人、不得填其性格动机。
9. **弟弟（林小野）信息真空**：ep21–ep26 前只给物件线索；不得提前写弟弟视角或让其现身。
10. **大雾/雾蚀不写成病毒丧尸**：吸入致失语失忆静止、救回后失忆；不得写尸变嗜血（R1 + 平台特加合规项）。
11. **小满不写成圣母也不写成冷血**：她心软会因收留陷险（这是缺陷不是优点），但每次涉险都要有"自己的判断"在内，不做被推动的挂件。
12. **猎兽会不脸谱化**：他们有专业器具与辨识能力（认兽识核），不写成一味喊口号的蠢反派。

## 六、维护规则

1. **写新集前**：先读本档案"成长轨迹线 + 关系网 + 写作红线"三区，确认人物没跳变、没 OOC。
2. **写新集后**：① 轨迹线追加本集锚点；② 关系网更新变化；③ 新人物建卡；④ 状态库照常更新（本档案不替代状态库）。
3. **分工不重叠**：
   - 宪法 §5 = 静态人设（几乎不改）
   - 本档案 = 成长轨迹/关系变化/红线（每集追加，只增不删）
   - 01-动态状态库 = 本集快照（位置/持有物/目标，每集覆盖）
   - 术语表 = 人物名字标准写法（防错字）
4. **禁止**：删除历史轨迹行；把状态库内容搬进来（两处重复）；未经 D2 决策门擅自改人物核心设定。
